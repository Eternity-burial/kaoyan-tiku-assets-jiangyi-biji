## 1.3 正文（笔记主线）

### §1 函数

#### 1. 函数概念

- 定义：$D\subset\mathbb{R}$，$\forall x\in D$ 按法则 $f$ 对应唯一 $y$，记 $y=f(x)$。
- 两要素：**定义域**与**对应法则**。
- 反函数：双射才存在；$y=f(x)$ 与 $y=f^{-1}(x)$ 关于 $y=x$ 对称；$[f^{-1}]'=1/f'$（$f'\ne0$）。

#### 2. 四大特性

| 特性 | 要点 |
|------|------|
| 有界性 | 等价于既有上界又有下界 |
| 单调性 | 区间上 $x_1<x_2\Rightarrow f(x_1)<f(x_2)$（增） |
| 奇偶性 | 定义域须关于原点对称；奇函数过原点（若 $0\in D$） |
| 周期性 | 可导周期函数导函数同周期 |

**奇偶与导数/积分互转**（笔记要点）：

- 可导奇 $\Rightarrow$ 导函数偶；可导偶 $\Rightarrow$ 导函数奇。
- 连续奇函数的全体原函数为偶；连续偶函数的原函数中**仅** $\int_0^x f$ 为奇。
- 连续周期 $f$（周期 $T$）的 $\int_0^x f$ 仍周期 $\iff$ $\int_0^T f=0$。

#### 3. 双曲与反三角（补充专题）

- $\sinh x=\dfrac{e^x-e^{-x}}2$，$\cosh x=\dfrac{e^x+e^{-x}}2$，$\cosh^2x-\sinh^2x=1$。
- $\operatorname{arsh}x=\ln(x+\sqrt{x^2+1})$，$\operatorname{arch}x=\ln(x+\sqrt{x^2-1})$（$x\ge1$），$\operatorname{arth}x=\dfrac12\ln\dfrac{1+x}{1-x}$（$|x|<1$）。
- 反三角主值：$\arcsin\in[-\frac\pi2,\frac\pi2]$，$\arccos\in[0,\pi]$，$\arctan\in(-\frac\pi2,\frac\pi2)$，$\operatorname{arccot}\in(0,\pi)$；$\arcsin x+\arccos x=\frac\pi2$。

#### 4. 有界性判别（补充）

- $C[a,b]\Rightarrow$ 有界。
- 开区间连续有界 $\Leftarrow$ 两端单侧极限均有限（非充要：$\sin\frac1x$ 有界但端点极限不存在）。
- $|f'|\le M$ 在有限区间 $\Rightarrow$ $f$ 有界（Lipschitz）；反之不真（$\sin x^2$，$\sqrt{x}$）。

### §2 极限

#### 1. 数列极限（笔记讲02）

**定义（$\varepsilon$-$N$）**：

$$\lim_{n\to\infty}x_n=A\iff\forall\varepsilon>0,\exists N,\ n>N\Rightarrow|x_n-A|<\varepsilon$$

- 子列：收敛 $\iff$ 任一子列收敛且极限相同；常用 **奇偶子列同极限**。
- 发散判别：存在发散子列，或两收敛子列极限不同。

**求/证数列极限的常用方法**（与30讲 ch2、李范「求极限的方法」及题型六–九对齐）：

- 单调有界准则；压缩映射（$|x_{n+1}-a|\le k|x_n-a|$，$0<k<1$）。
- 夹逼准则；海涅定理（归结为函数极限）。
- 定积分定义求 $n$ 项和（详见第3章）。

#### 2. 函数极限（笔记讲01）

**定义与单侧**：$\lim_{x\to x_0}f=A\iff f(x_0^-)=f(x_0^+)=A$。

必分左右极限的结构：分段分点；$e^{1/(x-x_0)}$；$\arctan\frac1{x-x_0}$。

**三大性质**：唯一性；局部有界；局部保号（脱帽/戴帽；取极限后严格不等号可能变 $\le/\ge$）。

#### 3. 无穷小、无穷大与阶

- 无穷小：$\lim f=0$；有界 $\times$ 无穷小 $=$ 无穷小。
- 无穷大与无穷小（非零）互为倒数。
- 阶：$\beta/\alpha\to0$ 高阶 $o(\alpha)$；$\to c\ne0$ 同阶；$\to1$ 等价。

**常用等价无穷小（$x\to0$）**：

$$\sin x\sim\tan x\sim\arcsin x\sim\arctan x\sim e^x-1\sim\ln(1+x)\sim x$$

$$1-\cos x\sim\frac{x^2}{2},\quad x-\sin x\sim\frac{x^3}{6},\quad\tan x-x\sim\frac{x^3}{3}$$

$$x-\arctan x\sim\frac{x^3}{3},\quad\tan x-\sin x\sim\frac{x^3}{2}$$

**增长阶梯（$x\to+\infty$）**：$\ln^\alpha x\ll x^\beta\ll a^x\ll x!\ll x^x$。

#### 4. 七大未定式与转化路径

| 类型 | 常用处理 |
|------|----------|
| $0/0$ | 等价代换、洛必达、泰勒（展开到首个非零项） |
| $\infty/\infty$ | 洛必达、抓大头、Stolz（数列） |
| $0\cdot\infty$ | 化商 |
| $\infty-\infty$ | 通分/有理化/提最高阶因子 |
| $1^\infty$ | $\lim(1+\alpha)^\beta=e^{\lim\alpha\beta}$ |
| $0^0,\infty^0$ | $e^{v\ln u}$ |

**两个重要极限**：$\lim_{x\to0}\frac{\sin x}{x}=1$；$\lim_{x\to\infty}(1+\frac1x)^x=e$。

**变限积分等价（秒杀）**：$x\to0$ 时 $f\sim ax^m$（$m>-1$）$\Rightarrow$ $\int_0^x f\sim\frac{a}{m+1}x^{m+1}$。

#### 5. 渐近线（与第2章应用衔接）

- 水平：$\lim_{x\to\pm\infty}f=b$；铅直：$\lim_{x\to x_0}f=\infty$；斜：$a=\lim f/x$，$b=\lim(f-ax)$。
- 同一侧水平与斜渐近线互斥。

### §3 连续与间断

#### 1. 连续定义

$f$ 在 $x_0$ 连续 $\iff$ 有定义 + 极限存在 + 极限值 $=$ 函数值。

#### 2. 间断点分类

| 类型 | 条件 | 例子 |
|------|------|------|
| 可去（第一类） | 左右极限存在相等，$\ne f(x_0)$ 或无定义 | $\frac{\sin x}{x}$ 在 $0$ |
| 跳跃（第一类） | 左右极限存在不等 | $\operatorname{sgn}x$ |
| 无穷（第二类） | 至少一侧为 $\infty$ | $1/x$ |
| 振荡（第二类） | 极限不存在且振荡 | $\sin\frac1x$ |

#### 3. 连续函数性质（李范 / 老姚 1.10）

- 有界性、最值定理、介值定理、零点定理（$f(a)f(b)<0\Rightarrow\exists\xi,\ f(\xi)=0$）。
