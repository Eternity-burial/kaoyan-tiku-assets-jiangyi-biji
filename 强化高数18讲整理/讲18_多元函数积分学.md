## 三、正文知识点与例题详解

### 一、计算三重积分（印刷页 244–253 / 物理页 257–266）

- 和式极限：$\lim_{n\to\infty}\sum\sum\sum g(...)\Delta x\Delta y\Delta z=\iiint_\Omega g(x,y,z)dv$。
- 交换积分次序：还原三重积分后按被积函数与区域形状换序。
- 保号性：连续 $f\ge0$ 且不恒为 0 ⟹ $\iiint_\Omega f>0$；对任意有界 $\Omega$ 积分为 0 ⟹ $f\equiv0$。
- 对称性（同二重积分）：普通对称（奇函数为 0、偶函数 2 倍）+ 轮换对称（$x,y,z$ 对调不变）。
- 直角坐标：先一后二（投影法）$\iint_D[\int_{z_1}^{z_2}fdz]dxdy$；先二后一（截面法）$\int_a^b[\iint_{D_z}f dxdy]dz$。
- 柱面坐标：$x=r\cos\theta,y=r\sin\theta$，$dv=rdrd\theta dz$（区域投影含 $x^2+y^2$ 时用）。
- 球面坐标：$x=r\sin\varphi\cos\theta,y=r\sin\varphi\sin\theta,z=r\cos\varphi$，$dv=r^2\sin\varphi drd\varphi d\theta$（区域为球/锥/球冠时用）。

**例18.1**（245）$\lim_{n\to\infty}\frac\pi{2n^3}\sum_{i,j,k}i^2\sin\frac{\pi j}{2n}\cos\frac kn=\frac\pi2\int_0^1x^2dx\int_0^1\sin\frac{\pi y}2dy\int_0^1\cos z\,dz$。
**例18.2**（245）累次积分与二重积分交换次序，化极坐标。
**例18.3**（246）$\iiint_\Omega(1-x^2-2y^2-3z^2)dv$ 取最大：$\Omega=1-x^2-2y^2-3z^2\ge0$（保号性）。
**课堂例题**（247）$\Omega: x+y+z=1$ 与坐标面围成，$I=\iiint(x+2y+3z)dv$，轮换对称 $=6\iiint z\,dv$。
**例18.4**（248）半球 $z=\sqrt{a^2-x^2-y^2}$ 与锥 $z=\sqrt{x^2+y^2}$ 围成，$I=\iiint(x+y+z)dv=\frac\pi8$：对称消 x,y，球坐标得 $\frac{\pi a^4}{8}=\frac\pi8\Rightarrow a=1$。
**例18.5**（250）顶点 A(0,1,1)、准线 $x^2+y^2=1,z=0$ 的锥面 $\frac{x^2}{(1-z)^2}+\frac{(y-z)^2}{(1-z)^2}=1$，形心 $(0,\frac14,\frac14)$（V=π/3，$\iiint z=\pi/12$）。
**例18.6**（251）曲线 $y^2=2z,x=0$ 绕 z 轴旋转面与 z=4 围成，$I=\iiint(x^2+y^2+z)dv$：旋转面 $x^2+y^2=2z$，先二后一+柱坐标。
**例18.7**（253）锥 $z=\sqrt{x^2+y^2}$ 与球 $z=\sqrt{a^2-x^2-y^2}$ 围成、密度 $\rho=\sqrt{x^2+y^2+z^2}$，质量 $m=\int_0^{2\pi}d\theta\int_0^{\pi/4}\sin\varphi d\varphi\int_0^a r^3dr$。

### 二、重积分应用（印刷页 253–256 / 物理页 266–269）

- 体积 $V=\iiint_\Omega dv$；重心 $\bar x=\frac{\iiint x\rho}{\iiint\rho}$（密度常数时即形心）；引力 $F_x=Gm\iiint\frac{\rho(x-x_0)}{r^3}dv$；转动惯量平面 $I_x=\iint y^2\rho$、空间 $I_z=\iiint(x^2+y^2)\rho$。

**例18.8**（253）$z=8-x^2-y^2$ 与 $z=2x$ 围成体积 $V=\iint_D[(8-x^2-y^2)-2x]dxdy$（$D:(x+1)^2+y^2=9$）。
**例18.9**（254）$\Omega=\{x^2+y^2\le z\le1\}$ 形心 $(0,0,\frac23)$。
**例18.10**（255）锥+柱+平面围成均匀物体对原点单位质点引力 $F=(0,0,2\pi G(\frac1{\sqrt2}+h-\sqrt{h^2+1}))$。
**例18.11**（256）锥 $y^2=x^2+z^2$ 与 y=1 围成关于 z 轴转动惯量 $I_z=\frac14\pi\rho$。

### 三、第一型曲线积分（印刷页 258–259 / 物理页 271–272）

- $\int_Lfds$ 物理背景为线密度质量；方法：代入曲线方程、几何意义 $\int_Lds=l$、形心公式 $\int_Lxds=\bar x l$、普通/轮换对称。

**例18.12**（259）$\Gamma:\begin{cases}x^2+y^2+z^2=1\\x+y+z=0\end{cases}$，$\oint_\Gamma(x^2+y^2)ds=\frac23\oint(x^2+y^2+z^2)ds=\frac23\cdot2\pi=\frac43\pi$（圆周半径 1，周长 2π）。

### 四、第一型曲面积分（印刷页 260–263 / 物理页 273–276）

- $\iint_\Sigma fdS$ 背景为面密度质量；方法：代入曲面方程、几何意义 $\iint_\Sigma dS=S_\Sigma$、形心、对称（普通/轮换/完全对称 $\frac13$ 公式）。
- 面积公式 $S=\iint_D\sqrt{1+z_x'^2+z_y'^2}dxdy$。

**例18.13**（263）球面 $x^2+y^2+z^2=a^2$，$I=\iint(\frac{x^2}2+\frac{y^2}3+\frac{z^2}4)dS=\frac{13}{36}a^2\cdot4\pi a^2=\frac{13}9\pi a^4$。
**例18.14**（263）球面 $(x-a)^2+(y-b)^2+(z-c)^2=R^2$，$\iint(x+y+z)dS=(a+b+c)4\pi R^2$。

### 五、第二型曲线积分（做功，印刷页 264–276 / 物理页 277–289）

- "类"对称性（注意 dx,dy 随对称轴正负号）；一投二代三计算（参数化）；格林公式 $\oint_LPdx+Qdy=\iint_D(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y})d\sigma$（闭合无奇点直接、有奇点挖洞、不闭合补线）。
- 两类曲线积分关系 $\int_\Gamma Pdx+Qdy+Rdz=\int_\Gamma(P\cos\alpha+Q\cos\beta+R\cos\gamma)ds$。
- 积分与路径无关等价命题（单连通 D）：与路径无关 ⟺ 任意闭曲线积分为 0 ⟺ 全微分 ⟺ 全微分方程 ⟺ 梯度场 ⟺ $\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}$；原函数用变限积分法或凑微分法。
- 空间曲线：一投二代三计算 / 斯托克斯公式 $\oint_\Gamma Pdx+Qdy+Rdz=\iint_\Sigma(\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z})dydz+\cdots$。

### 六、第二型曲面积分（通量，印刷页 276–287 / 物理页 289–300）
