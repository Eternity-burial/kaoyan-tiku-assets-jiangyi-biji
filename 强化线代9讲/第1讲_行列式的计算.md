# 强化第1讲 行列式的计算

> 来源：强化线代9讲.pdf 物理页12–20｜本章完结于物理页20

## 0. 框架：行列式三向解法
- O1（盯住目标1）具体型（a_ij 已给出）：化为基本形行列式、加边法、递推法（高阶→低阶）、数学归纳法（低阶→高阶）。
- O2（盯住目标2）抽象型（a_ij 未给出）：用行列式的性质、用矩阵知识、用相似理论。

## 一、具体型行列式的计算
### 1 化为基本形行列式
- 主对角线行列式 = ∏a_ii（上三角/下三角/对角均同）。
- 副对角线行列式 = (−1)^(n(n−1)/2)·a_1n·a_2(n−1)⋯a_n1。
- 拉普拉斯展开：
  - |A O; O B|=|A C; O B|=|A O; C B|=|A||B|（主对角分块）；
  - |O A; B O|=|C A; B O|=|O A; B C|=(−1)^(mn)|A||B|（副对角分块，A 为 m 阶、B 为 n 阶）。
- 范德蒙德行列式：|1 x_i x_i² … x_i^(n−1)| = ∏(x_j−x_i)（1≤i<j≤n）。
- 注（处理手段）：
  1. 所给行列式就是基本形或接近基本形 → 直接套公式或简单处理；
  2. 按零元素多的行或列展开；
  3. 用性质对差别最小的对应位置元素处理，尽可能化零后再展开；
  4. 行（列）和相等：所有列加到第 1 列（或行加到第 1 行），提出公因式；
  5. 元素中含 x ⇒ 行列式是 x 的多项式。
### 2 加边法
- 适用：一开始不宜用互换/倍乘/倍加性质的行列式；n 阶加一行一列升为 n+1 阶。
- 加边技巧：添加在第 1 列且为 [1,0,…,0]^T，第 1 行其余元素可任意添加，行列式值不变。
### 3 递推法（高阶→低阶）
- 建立 D_n 与 D_(n−1)（甚至 D_(n−2)）的递推关系；D_(n−1) 与 D_n 须有完全相同元素分布规律。
- 注：元素分布规律应从右下角往左上看出；选第 1 列展开才得 D_(n−1)，若选第 n 列展开余子式破坏规律无法递推。
- 典型递推：D_(k+1)=b·D_k+a_(k+1) ⇒ D_n=bⁿ+a1b^(n−1)+…+a_(n−1)b+a_n。
### 4 数学归纳法（低阶→高阶）
- 适用：告知结果、要求证明的 n 阶行列式问题。
- 第一数学归纳法（F(D_n,D_(n−1))=0）：验 n=1 → 假设 n=k → 证 n=k+1。
- 第二数学归纳法（F(D_n,D_(n−1),D_(n−2))=0）：验 n=1、2 → 假设 n<k → 证 n=k（k≥3）。
- 选法：要求计算行列式优先递推法；要求证明优先数学归纳法。

## 二、抽象型行列式的计算
### 1 用行列式的性质
- 用性质将所求行列式化成已知行列式。
### 2 用矩阵知识
- |AB|=|A||B|（同阶方阵）；要善于发现 AB：如列向量组合可写成 A·B 乘积。
- |A+B|≠|A|+|B|，须恒等变形为乘积：① 由题设 E=AA^T；② E=AA⁻¹ 等。
- 判断 |A|=0 的途径：
  1. |A|=k|A|，k≠1（常考 |A|=(−1)ⁿ|A|，n 为奇数）；
  2. A 有特征值 0；
  3. Ax=0 有非零解；
  4. r(A)<n；
  5. 行（列）向量组线性相关；
  6. 反证法：设 A 可逆推矛盾。
- 伴随公式：|A*|=|A|^(n−1)；|(A*)*|=|A|^((n−1)²)（=||A|^(n−2)A|）；更全公式在第3讲"四、2.(2)"。
### 3 用相似理论
- A∼B ⇒ |A|=|B|；|A|=∏λ_i；主要考：① |λE−A|=0 求特征值；② 用特征值求行列式。
- 行和相等矩阵（每行元素和相同 k）特征值结论：λ1=k[1+(n−1)a]（单重）、λ2=k(1−a)（n−1 重），最大特征值依参数比较取。
