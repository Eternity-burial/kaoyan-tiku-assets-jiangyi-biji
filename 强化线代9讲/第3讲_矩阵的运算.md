# 强化第3讲 矩阵的运算

> 来源：强化线代9讲.pdf 物理页25–51（印刷1–27）｜本章完结于物理页51

## 0. 框架：三向解题法（矩阵运算）
- 矩阵乘法形状大观（O1+D1+D23）、证 A=O（O1）、计算 A^n（O2）、A^T A/A*/A⁻¹/初等矩阵（O3+D2 脱胎换骨）、分块矩阵（O4）、求解矩阵方程（O5+D2）。

## 一、矩阵乘法的形状大观
- 行|列=内积（1×1）：[x1,x2,x3]·[1;1;1]=x1+x2+x3；α^Tβ=β^Tα。
- A=αβ^T ⇒ r(A)=1，且 A^n=[tr(A)]^(n−1)·A。
- 右乘单位阵=取出对应列向量；副1阵（换列阵）；SA=λI 型可对角化分析。

## 二、转置与伴随
- (A^T)^T=A；(AB)^T=B^T A^T；A^T=[A_ij]^T=A_ji。
- r(A*) 公式（A 为 n 阶方阵）：r(A)=n ⇒ r(A*)=n；r(A)=n−1 ⇒ r(A*)=1；r(A)<n−1 ⇒ r(A*)=0。
- (A*)* 结论：n=2 时 (A*)*=A；n>2 且 A 可逆时 (A*)*=|A|^(n−2)A；n>2 且 A 不可逆时 (A*)*=O。
- A∼B ⇒ A*∼B*（可逆直接推；不可逆用 A_t=A+tE 扰动 + t→0 连续延拓）；A 与 B 合同 ⇒ A* 与 B* 合同。

## 三、逆矩阵
- 定义：AB=E ⇒ 互为逆矩阵（AB=BA、A⁻¹=B）。
- 性质：① (A⁻¹)⁻¹=A；② (AB)⁻¹=B⁻¹A⁻¹（穿脱原则）；③ (kA)⁻¹=(1/k)A⁻¹；④ (A^T)⁻¹=(A⁻¹)^T；⑤ |A⁻¹|=1/|A|。
- 求逆：具体型 A⁻¹=(1/|A|)A* 或 [A,E] 行变换；抽象型恒等变形创造 AB=E 或 A=BC。
- 多项式技巧：带余除法分解创造 AB=E；A=αα^T−E 型配参数 k 求逆；A³=O ⇒ E±A 可逆。

## 矩阵可逆的充要条件大观（蓝框）
- 定义类：① 存在 B 使 AB=BA=E；② BA=E；③ AB=E。
- 行列式类：④ |A|≠0。
- 初等变换类：⑤ 等价标准形为 E；⑥ 行变换化 E；⑦ 列变换化 E；⑧ 初等矩阵乘积。
- 秩类：⑨ r(A)=n；⑩–⑬ 对任意 C，r(AC)=r(C) 或 r(CA)=r(C)。
- 方程组类：⑭ Ax=0 只有零解；⑮ Ax=β 唯一解；⑯ Ax=β 有解。
- 向量组类：⑰ AX=O 只有零解；⑱ AX=C 唯一解；⑲ AX=C 有解；⑳ 列向量组线性无关；㉑ 行向量组线性无关；㉒ 列向量组是 Rⁿ 的基；㉓ 行向量组是 Rⁿ 的基。
- 特征值类：㉔ 0 不是 A 的特征值。
- 正定类：㉕ A^TA 正定；㉖ AA^T 正定；㉗ A^TA 特征值全正；㉘ A^TA 与 E 合同；㉙ A^TA 正惯性指数 n；㉚ A^TA 顺序主子式全正。

## 四、初等变换与满秩分解
- 使用场合：计算行列式、求矩阵秩、求向量组秩、等价标准形、成对初等变换（行列混用）。
- 拼法：列拼行变换 [A,E]→[E,A⁻¹]；行拼列变换 [A;E]→[E;A⁻¹]。
- 列满秩 ⇔ 存在可逆 P 使 A=P[E_n;O]；行满秩 ⇔ 存在可逆 Q 使 A=[E_m;O]Q。

## 五、分块矩阵
- 定义：横线纵线分割成子块，子块作元素。
- 数乘、乘法（子块相乘，左×右不能互换）。
- 分块对角阵幂：diag(A,B)^k=diag(A^k,B^k)。
- 分块三角逆：[B O; D C]⁻¹=[B⁻¹ O; −C⁻¹DB⁻¹ C⁻¹]；[B D; O C]⁻¹=[B⁻¹ −B⁻¹DC⁻¹; O C⁻¹]；[O B; C D]⁻¹=[−C⁻¹DB⁻¹ C⁻¹; B⁻¹ O]；[D B; C O]⁻¹=[O C⁻¹; B⁻¹ −B⁻¹DC⁻¹]。
- 主对角分块逆：diag(A1,…,As)⁻¹=diag(A1⁻¹,…,As⁻¹)；副对角分块类似（伴随公式族）。
- AB=O 结论：B 按列分块 ⇒ Aβ_i=0（β_i 是 Ax=0 的解），r(A)+r(B)≤n。
- AB=C 结论：C 的行向量是 B 的行向量组的线性组合；C 的列向量是 A 的列向量组的线性组合。
- 化零技巧：横拼左同多化零 [AB,A]→[O,A]；竖拼右同多化零 [AB;B]→[O;B]。
- 形式化归结乘块：r(AB;B)=r(B)；r(AB)=r(B) ⇔ ABx=0 与 Bx=0 同解；A^TA 与 A 的行向量组等价。
- 解题思路：分块矩阵也是矩阵，公式（如 AA*=|A|E）对分块同样成立；新分块先想①②或初等变换。

## 六、求解矩阵方程
- 定义：含未知矩阵的方程；目标化简为 AX=B、XA=B 或 AXB=C。
- 化简手段：① 消公因式：CA=CB 且 C 可逆 ⇒ A=B（注：C 列满秩亦可）；② 提取公因式；③ 移项；④ 用公式：AA*=|A|E、A*=|A|A⁻¹、(A*)*=|A|^(n−2)A、A²−E=(A+E)(A−E)、A*B^T=(BA)^T、A*B*=(BA)*、(A⁻¹)*=(A*)⁻¹、(A*)^T=(A^T)*（注：AC=BC 且 C 行满秩 ⇒ A=B）。
- 求解：
  - A 可逆：X=A⁻¹B；XA=B ⇒ X=BA⁻¹；AXB=C ⇒ X=A⁻¹CB⁻¹。
  - A 不可逆（AX=B）：X、B 按列分块，解 s 个方程组 Aξ_i=β_i。
  - 兜底：待定元素法 X=(x_ij) 代入得线性方程组。
  - 有解条件：AX=B 有解 ⇔ r(A)=r([A,B])。
- 难题思路：D21 观察研究对象 + D23 化归经典形式找背后考点（如 B²=A 两边乘 A=B² 得 B²A=AB²，试 BA=AB）。
