# 强化第5讲 线性方程组

> 来源：强化线代9讲.pdf 物理页60–74｜本章完结于物理页74

## 0. 框架：三向解题法
- 理论总结（D1）：齐次 Ax=0、非齐次 Ax=b；问题（D1+D22+P2 反证）：一般求解、公共解、同解；几何意义（仅数学一，D43 数形结合）。

## 一、理论总结
### 齐次 Ax=0
- 解的性质：解的线性组合仍为解。
- 基础解系：① 是解；② 线性无关；③ s=n−r(A)。
- 有非零解 ⇔ r(A)<n；通解 x=k1ξ1+…+k_{n−r}ξ_{n−r}。
- 解与系数正交：β 为解 ⇒ A 的行向量 a_i^T 与 β 正交（a_i^Tβ=0）。
### 非齐次 Ax=b
- η1−η2 为导出组 Ax=0 的解。
- 唯一解 r(A)=r([A,b])=n；无穷多解 r(A)=r([A,b])<n；无解 r(A)≠r([A,b])。
- 通解=特解 η*+导出组通解（导出组即对应齐次方程组）。
- 克拉默法则：n 个方程 n 个未知数且 |A|≠0 时 x_i=D_i/|A|。
- 注：η*、η*+ξ1、…、η*+ξ_{n−r} 线性无关，且任一解可由其线性表示。

## 二、几何意义（仅数学一）
- 记号：Π_i 第 i 张平面；α_i 为 A 的行向量（法向量）；β_i 为 Ā 的行向量 [a_i,b_i,c_i,d_i]。
- 蓝框判别（i≠j）：
  1. α_i 与 α_j 线性相关 ⇔ Π_i 与 Π_j 平行或重合；
  2. α_i 与 α_j 线性无关 ⇔ Π_i 与 Π_j 相交；
  3. β_i 与 β_j 线性相关 ⇔ Π_i 与 Π_j 重合；
  4. β_i 与 β_j 线性无关 ⇔ Π_i 与 Π_j 不重合。
- 有解情形（r(A)=r(Ā)）：
  - 情形1 r=3：交于一点（唯一解）；
  - 情形2 r=2 且 β 中任意两向量无关：交于一条直线（任何两面不重合）；
  - 情形3 r=2 且 β 中有两向量相关：两平面重合、第三面与之相交（存在两面重合）；
  - 情形4 r=1：三面重合。
- 无解情形（r(A)≠r(Ā)）：
  - 情形1 r(A)=2、r(Ā)=3 且 α 中任意两向量无关：三面两两相交、交线相互平行；
  - 情形2 r(A)=2、r(Ā)=3 且 α 中有两向量相关：两面平行、第三面与它们相交；
  - 情形3 r(A)=1、r(Ā)=2 且 β 中任意两向量无关：三面相互平行但不重合；
  - 情形4 r(A)=1、r(Ā)=2 且 β 中有两向量相关：两面重合、第三面与它们平行但不重合。

## 三、公共解问题（O2+D1+D22）
- 齐次公共非零解：联立 [A;B]x=0 求解（基本做法）；有公共非零解 ⇔ r([A;B])<n。
- 非齐次公共解：本质也是联立解；有公共解 ⇔ r([A;B])=r([A β;B γ])。

## 四、同解问题（O3+D1+D22）
### 齐次同解
- Ax=0 与 Bx=0 同解 ⇔ r([A;B])=r(A)=r(B) ⇔ A、B 行向量组等价 ⇔ 存在 P,Q 使 B=PA、A=QB。
- 证明链：基础解系等价 ⇔ r(I)=r(II)=r(I,II) ⇔ r(A)=r(B) 且 A 的解均为 B 的解。
### 非齐次同解（I: Ax=β，II: Bx=γ 均有解）
- (I)与(II)同解 ⇔ 导出组同解且(I)(II)有公共解 ⇔ r([A β;B γ])=r([A;B])=r(A)=r(B) ⇔ [A,β]与[B,γ]行向量组等价。
- 判别：r([A,α])≠r([B,β]) ⇒ Ax=α 与 Bx=β 不同解。
