一、随机事件的关系与运算

（一）随机事件与样本空间的概念
►1. 随机试验
称一个试验为随机试验（简称试验），如果：（1）试验可以在相同的条件下重复进行；（2）每次试验的可能结果不止一个，并且能事先明确试验的所有可能结果；（3）进行一次试验之前不能确定哪一个结果会出现．用字母 $E$ 或 $E_1, E_2, \cdots$ 表示．
►2. 随机事件
（1）基本事件与样本空间  随机试验最基本的结果，称为基本事件或样本点，记作 $\omega$，每次试验必定出现且只能出现一个基本事件．一切基本事件的集合，称为样本空间，记作 $\Omega$，即 $\Omega = \{\omega\}$．
（2）随机事件  随机试验的一个结果，称为随机事件，简称为事件，用字母 $A, B, C, \cdots$ 表示．事件可视为样本空间 $\Omega$ 的子集．在每次试验中，当且仅当事件 $A$ 所包含的某一基本事件出现时，称事件 $A$ 发生．在每次试验中，一定出现的结果，称为必然事件，即为样本空间 $\Omega$．在任何一次试验中都不会出现的结果，称为不可能事件，即为空集 $\varnothing$．
事件是一个集合，因而事件间的关系与事件的运算自然按集合论中集合之间的关系和集合的运算来处理．关于集合间的关系和集合的运算，考生重点要知道它们在概率中的含义．

（四）事件的运算性质
在进行事件运算时，经常要用到以下定律．设 $A, B, C, A_i (i=1, 2, \cdots)$ 为事件，则有
(1) 吸收律  若 $A \subset B$，则 $A \cup B = B$, $AB = A$；
(2) 交换律  $A \cup B = B \cup A$, $AB = BA$；
(3) 结合律  $A \cup B \cup C = (A \cup B) \cup C = A \cup (B \cup C)$；$ABC = (AB)C = A(BC)$；
(4) 分配律  $A(B \cup C) = AB \cup AC$；$A \cup (BC) = (A \cup B)(A \cup C)$；
       $(A \cup C)(B \cup C) = AB \cup C$；$A \cap \left(\bigcup_{i=1}^\infty A_i\right) = \bigcup_{i=1}^\infty (A \cap A_i)$；
(5) 对偶律  $\overline{A \cup B} = \overline{A} \ \overline{B}$；$\overline{A \cap B} = \overline{A} \ \overline{B}$；$\overline{\bigcup_{i=1}^n A_i} = \bigcap_{i=1}^n \overline{A_i}$，$\overline{\bigcap_{i=1}^n A_i} = \bigcup_{i=1}^n \overline{A_i}$．

【例1.1】 设 $A, B, C$ 为随机事件，$A$ 发生必导致 $B$ 与 $C$ 最多一个发生，则有
(A) $A \subset BC$  (B) $A \supset BC$  (C) $A \subset \overline{BC}$  (D) $A \supset \overline{BC}$
【分析】 $B$ 与 $C$ 最多有一个发生就是 $B$ 与 $C$ 不可能同时发生，即 $BC = \varnothing$，从而 $\overline{BC} = \Omega, A \subset \overline{BC} = \Omega$．故选(C)．

【例1.2】 已知 $(A \cup X)(\overline{A} \cup \overline{X}) \cup A \cup \overline{X} \cup A \cup \overline{X} = B$，则 $X = $ ______．
【分析】 由事件的运算性质，可得
$(A \cup X)(\overline{A} \cup \overline{X}) = A\overline{A} \cup X\overline{X} = \varnothing \cup X\overline{X} = X\overline{X} = X, \quad A \cup X\overline{X} = A$
$(A \cup X) \cup A \cup X = A X \cup A \overline{X} = (A \cup A)\overline{X} = \overline{X}$
于是 $(A \cup X)(\overline{A} \cup \overline{X}) \cup A \cup X \cup A \cup X = X \cup \overline{X} = \Omega = B$，从而 $X = \overline{B}$．

评注 事件运算的一般顺序为：“括号” $\rightarrow$ “逆” $\rightarrow$ “积” $\rightarrow$ “和”或“差”．

【例1.3】 设随机事件 $A, B$ 满足条件 $A \cup C = B \cup C$ 和 $C - A = C - B$，则 $\overline{A}B \cup \overline{B}A = $ ______．
【分析一】 由 $C - A = C - B \Rightarrow C\overline{A} = C\overline{B}$．①
又由 $A \cup C = B \cup C \Rightarrow \overline{A}C = \overline{B}C$．②
由 ① + ② 可得 $C\overline{A} + \overline{A}C = \overline{B}C + \overline{B}C$，即 $\overline{A} = \overline{B}$，亦即 $A = B$．
因此 $\overline{A}B \cup \overline{B}A = \overline{B}B \cup \overline{B}B = \varnothing$．
【分析二】 由于 $A = (A \cup C) - (C - A) = (B \cup C) - (C - B) = B$，因此 $\overline{A}B \cup \overline{B}A = \varnothing$．

二、随机事件的概率

（一）概率与条件概率的概念
概率与长度、面（体）积、质量…是同一类概念，概率是一种度量．概率是事件 $A$ 出现可能性大小的数值度量，记为 $P(A)$．
►1. 概率的公理化定义
称 $P(A)$ 为事件 $A$ 的概率，如果 $P(\cdot)$ 满足下列条件：
(1) 非负性  对于每一个事件 $A_i$，有 $P(A_i) \geqslant 0$；
(2) 规范性  对于必然事件 $\Omega$，有 $P(\Omega) = 1$；
(3) 可列可加性  设事件 $A_1, \cdots, A_n, \cdots$ 两两互不相容，即对于 $i \neq j, A_i A_j = \varnothing$（$i, j = 1, 2, \cdots$），则
$P(A_1 \cup A_2 \cup \cdots) = P(A_1) + P(A_2) + \cdots$，即 $P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)$．
►2. 条件概率
设 $A, B$ 是两个事件，且 $P(A) > 0$，则称在已知事件 $A$ 发生的条件下事件 $B$ 发生的概率为条件概率，记为 $P(B \mid A)$，并定义
$P(B \mid A) = \frac{P(AB)}{P(A)} \quad (P(A) > 0)$．
【注】 ① 条件概率 $P(\cdot \mid A)$ 也是一种概率，条件概率的一切性质和重要结论对条件概率都适用．
② 计算条件概率 $P(B \mid A)$ 的两种方法：
方法 $1^\circ$ 按条件概率的含义，直接求出 $P(B \mid A)$，注意到，在求 $P(B \mid A)$ 时已知事件 $A$ 已发生，样本空间 $\Omega$ 中所有不属于 $A$ 的样本点都被排除，原有的样本空间 $\Omega$ 缩减成为 $\Omega' = A$．在缩减了的样本空间 $\Omega' = A$ 中计算事件 $B$ 的概率就得到 $P(B \mid A)$．
方法 $2^\circ$ 在 $\Omega$ 中计算 $P(AB)$ 及 $P(A)$，再按条件概率的定义式求得 $P(B \mid A)$．

（二）概率的基本性质和基本公式
►1. 概率的基本性质
【性质1】 $P(\varnothing) = 0$．
【性质2】 有限可加性  设事件 $A_1, A_2, \cdots, A_n$ 两两互不相容，则
$P(A_1 \cup A_2 \cup \cdots \cup A_n) = P(A_1) + P(A_2) + \cdots + P(A_n)$．
【性质3】 减法公式  如果 $A, B$ 是任意事件，则 $P(A - B) = P(A) - P(AB)$；
           如果 $A \supset B$，则 $P(A - B) = P(A) - P(B)$，$P(A) \geqslant P(B)$．
【性质4】 对于任一事件 $A$，有 $0 \leqslant P(A) \leqslant 1$．
【性质5】 逆事件的概率  对于任一事件 $A$，有 $P(\overline{A}) = 1 - P(A)$．
【性质6】 加法公式  对于任意三个事件 $A, B, C$，有
(1) $P(A \cup B) = P(A) + P(B) - P(AB)$；
(2) $P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(BC) - P(AC) + P(ABC)$．
【注】 在计算一些事件和的概率，即计算若干个事件中至少有一个事件发生的概率时，用概率的加法公式，但有时用对立事件的性质比较方便．特别是当这些事件相互独立的时候．
►2. 概率的基本公式
(1) 乘法公式
$P(AB) = \begin{cases} P(A)P(B \mid A), & \text{当 } P(A) > 0, \\ P(B)P(A \mid B), & \text{当 } P(B) > 0; \end{cases}$
$P(A_1 A_2 \cdots A_n) = P(A_1)P(A_2 \mid A_1)P(A_3 \mid A_1 A_2) \cdots P(A_n \mid A_1 \cdots A_{n-1}) \quad (P(A_1 \cdots A_{n-1}) > 0)$
【注】 当 $A_i$ 先于 $A_{i+1}$ 发生时用乘法公式．
(2) 全概率公式
如果事件 $A_1, \cdots, A_n$ 构成一个完备事件组，即它们两两互不相容，其和为 $\Omega$；并且 $P(A_i) > 0, i=1, 2, \cdots, n$，则对任意事件 $B$，有
$P(B) = \sum_{i=1}^n P(BA_i) = \sum_{i=1}^n P(A_i)P(B \mid A_i)$．
特别地，上式中取 $n=2$，并将 $A_1$ 记为 $A$，此时 $A_2$ 就是 $\overline{A}$，那么全概率公式成为
$P(B) = P(A)P(B \mid A) + P(\overline{A})P(B \mid \overline{A})$．
(3) 贝叶斯公式
如果事件 $A_1, \cdots, A_n$ 构成一个完备事件组，且 $P(A_i) > 0, i=1, \cdots, n, P(B) > 0$，则对正整数 $m$，有
$P(A_m \mid B) = \frac{P(BA_m)}{P(B)} = \frac{P(A_m)P(B \mid A_m)}{\sum_{i=1}^n P(A_i)P(B \mid A_i)} \quad (1 \leqslant m \leqslant n)$．
特别地，上式中取 $n=2$，并将 $A_1$ 记为 $A$，此时 $A_2$ 就是 $\overline{A}$，那么贝叶斯公式成为条件概率公式，即
$P(A \mid B) = \frac{P(AB)}{P(B)} = \frac{P(B)P(A \mid B)}{P(A)P(B \mid A) + P(\overline{A})P(B \mid \overline{A})}$
【注】 全概率公式与贝叶斯公式使用的关键是要找到导致事件 $B$ 发生的完备事件组．

（三）概率的计算
►1. 直接计算
在某些情况下，利用试验结果的等可能性，可以直接计算随机事件的概率．

(1) 古典概型  如果试验只有 $n$ 个基本事件，并且每一个基本事件出现的可能性相同，对于该试验的事件 $A$，则有
$P(A) = \frac{A \text{ 所包含的基本事件数} k}{\text{基本事件的总数} n} = \frac{k}{n}$．
(2) 几何概型  若试验的样本空间是几何区域（直线、面积或体积），其度量大小可用 $S_\Omega$ 表示，且任意点落在度量相同的子区域内是等可能的．当事件 $A$ 为 $\Omega$ 的某一子区域，其度量为 $S_A$，则事件 $A$ 的概率为
$P(A) = \frac{S_A}{S_\Omega}$．
【注】 ① 古典概型与几何概型都有某种等可能性，或者说“均匀性”．两个概型的区别在于：几何概型的样本空间是无限（不可列）的，而古典概型的样本空间是有限的．
② 古典概型问题的主要计算工具是排列和组合，而几何概型问题的主要计算工具是用几何方法计算长度、面积、体积等，也会用到微积分计算．
③ 古典概型的难点在于当选定样本空间后，正确计算事件 $A$ 所包含样本点的个数；而几何概型难在模型化（如候车问题、会面问题等）：如何化为数学问题．
►2. 用频率估计概率
用事件 $A$ 在大量重复试验中出现的频率 $f_n(A) = \frac{A \text{ 在} n \text{次试验中出现的次数} k}{\text{试验次数} n}$ 作为概率 $P(A)$ 的近似值．
►3. 概率的推算
利用概率的基本性质、基本公式和事件的独立性，由简单事件的概率推算较复杂事件的概率．
►4. 利用概率分布计算概率

【例1.4】 抛掷两枚骰子，在第一枚骰子出现的点数能够被3整除的条件下，求两枚骰子出现的点数之和大于8的概率．
【解】 设 $A$ 表示事件“第一枚骰子出现的点数能够被3整除”，$B$ 表示事件“两枚骰子出现的点数之和大于8”．抛掷两枚骰子所出现的点数为 $(i, j)$ ($i, j=1, 2, \cdots, 6$)，其中 $i, j$ 分别表示抛掷第一枚骰子和抛掷第二枚骰子出现的点数，共有 $6^2 = 36$ 种结果，即有36个基本事件．抛掷第一枚骰子出现3点或6点时，才能被3整除，因此事件 $A$ 包含2个基本事件，从而
$P(A) = \frac{2}{6} = \frac{1}{3}$．
事件 $A$ 和事件 $B$ 的交 $AB = \{(3, 6), (6, 3), (6, 4), (6, 5), (6, 6)\}$，即包含5个基本事件，因此
$P(AB) = \frac{5}{36}$．
所求概率即为条件概率
$P(B \mid A) = \frac{P(AB)}{P(A)} = \frac{\frac{5}{36}}{\frac{1}{3}} = \frac{5}{12}$．

评注 ① 如果考虑到事件 $A$ 包含 $2 \times 6 = 12$ 个基本事件，在这12个基本事件中能够导致事件 $B$ 发生的基本事件有5个，则所求的条件概率 $P(B \mid A) = \frac{5}{12}$．
② 古典概型中概率的计算关键是正确计算出样本空间 $\Omega$ 与所求事件 $A$ 中的基本事件数，其中较困难的是事件 $A$ 的基本事件数的计算，既不能漏算，也不能重复计算．

### 三、事件的独立性与独立重复试验

#### (一) 事件的独立性
**1. 独立性的定义**
**(1) 两个事件的独立性**：
称事件 $A$ 与 $B$ **相互独立**，如果它们满足等式：
$$P(AB) = P(A)P(B)$$
**(2) 三个事件的相互独立**：
需满足以下四个等式：
$$P(AB) = P(A)P(B)$$
$$P(AC) = P(A)P(C)$$
$$P(BC) = P(B)P(C)$$
$$P(ABC) = P(A)P(B)P(C)$$
如果 $A, B, C$ 仅满足前三个等式，则称为**两两独立**。
**(3) $n$ 个事件的相互独立性**：
称 $n$ 个事件 $A_1, \cdots, A_n$ 相互独立，如果它们中任意 $k$ ($2 \le k \le n$) 个事件的积事件的概率都等于各事件概率的乘积。

**2. 独立性的性质**
**(1) 换算性质**：
设 $A, B$ 为两个事件：
*   $A$ 与 $B$ 相互独立 $\iff P(AB) = P(A)P(B)$
*   $A$ 与 $\bar{B}$ 相互独立 $\iff P(A)P(B) > 0, P(B) < 1, P(A|B) = P(A|\bar{B}), P(B|A) = P(B)$
*   $P(B|A) + P(\bar{B}|\bar{A}) = 1 \quad (0 < P(A) < 1)$
**(2) 对立事件运算保持独立性**：
$$A \text{ 与 } B \text{ 独立} \iff A \text{ 与 } \bar{B} \text{ 独立} \iff \bar{A} \text{ 与 } B \text{ 独立} \iff \bar{A} \text{ 与 } \bar{B} \text{ 独立}$$

<!-- 物理页481 印刷页471 -->

**(接上页性质)**
**(3) $n$ 个事件的扩展性质**：
1.  $\text{其中任意 } m (2 \le m \le n) \text{ 个事件也相互独立}$
2.  $\text{其中任意一个事件与其余任意 } m (2 \le m \le n) \text{ 个事件运算（和、差与交）也独立}$
3.  $\text{将任意 } m (2 \le m \le n) \text{ 个事件分别换成其对立事件后所得 } n \text{ 个事件也独立}$

#### (二) 独立重复试验与伯努利公式
**1. 独立重复试验**
*   **定义**：如果在两个或多个试验中与各试验相联系的事件之间相互独立，且同一事件在各个试验中出现的概率相同，则称这些试验是**独立重复试验**。
*   **伯努利试验**：只有两种对立结果的试验称为伯努利试验。如果一个伯努利试验独立地重复进行 $n$ 次，则称这样的试验模型为 **$n$ 重伯努利概型**。

**2. 伯努利公式 (二项概率公式)**
设在每次试验中 $P(A) = p (0 < p < 1)$，则在 $n$ 重伯努利试验中事件 $A$ 发生 $k$ 次的概率 $P(A_k)$ 为：
$$P(A_i) = \text{C}_n^k p^k q^{n-k} \quad (k=0, 1, 2, \cdots, n)$$
其中 $0 < p < 1, q = 1 - p$。
如果用 $X$ 表示 $n$ 重伯努利概型中事件 $A$ 发生的次数，则 $X$ 服从二项分布 $B(n, p)$。
**注**：伯努利概型的特征是只论次数，不管顺序。

**独立重复射击解题技巧**：
凡是涉及至少发生一次的问题时，往往通过对立事件的概率来解决较为方便。
$$P(A_1 \cup A_2 \cup A_3) = 1 - P(\bar{A}_1 \bar{A}_2 \bar{A}_3) = 1 - P(\bar{A}_1)P(\bar{A}_2)P(\bar{A}_3) = 1 - (1-p)^3$$
