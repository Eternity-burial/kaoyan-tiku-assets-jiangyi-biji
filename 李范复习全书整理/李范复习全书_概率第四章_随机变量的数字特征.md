## 内容概要与重难点提示
随机变量的数字特征是描述随机变量分布特征的数字，它们能够集中地刻画出随机变量取值规律的特点。随机变量的数字特征考试大纲要求的是数学期望、方差、标准差、各阶原点矩与中心矩、协方差与相关系数。

关于随机变量的数字特征不仅要理解其概念，还应会运用定义与性质计算随机变量及其函数的数字特征。特别是计算一个或两个随机变量函数的数学期望，掌握常用分布的数字特征与其分布参数间的关系。

## 考核知识点讲解

### 一、随机变量的数学期望和方差

#### （一）随机变量的数学期望的概念与性质

**1. 随机变量的数学期望的概念**

(1) 离散型随机变量的数学期望 设离散型随机变量 $X$ 的分布律为 $P \{ X = x_i \} = p_i (i = 1, 2, \cdots)$，若无穷级数 $\sum_{i=1}^{\infty} x_i p_i$ 绝对收敛，则称无穷级数的和 $\sum_{i=1}^{\infty} x_i p_i$ 为随机变量 $X$ 的数学期望或均值。记作 $EX$ 或 $E(X)$，即
$$ EX = E(X) = \sum_{i=1}^{\infty} x_i p_i. \quad (4.1) $$

# (二) 随机变量函数的数学期望

## ▶1. 一个随机变量$X$的函数 $Y = g(X)$ 的数学期望

(1) 设 $X$ 是离散型随机变量, 其概率分布为
$P\{X = x_k\} = p_k, k=1, 2, \cdots,$
如果无穷级数 $\sum_{k=1}^{\infty} g(x_k)p_k$ 绝对收敛, 则随机变量 $Y = g(X)$ 的数学期望为
$$E(Y) = E[g(X)] = \sum_{k=1}^{\infty} g(x_k)p_k \quad (4.3)$$
(2) 设连续型随机变量 $X$ 的概率密度为 $f(x)$, 如果反常积分 $\int_{-\infty}^{+\infty} g(x)f(x) dx$ 绝对收敛, 则随机变量 $Y = g(X)$ 的数学期望为
$$E(Y) = E[g(X)] = \int_{-\infty}^{+\infty} g(x)f(x) dx. \quad (4.4)$$

## ▶2. 二维随机变量 $(X, Y)$ 的函数 $Z = g(X, Y)$ 的数学期望

(1) 设二维离散型随机变量 $(X, Y)$ 的概率分布为
$P\{X = x_i, Y = y_j\} = p_{ij}, i, j = 1, 2, \cdots,$
如果无穷级数 $\sum_{j=1}^{\infty} \sum_{i=1}^{\infty} g(x_i, y_j)p_{ij}$ 绝对收敛, 则随机变量 $Z = g(X, Y)$ 的数学期望为
$$E(Z) = E[g(X, Y)] = \sum_{j=1}^{\infty} \sum_{i=1}^{\infty} g(x_i, y_j)p_{ij}. \quad (4.5)$$
(2) 设二维连续型随机变量 $(X, Y)$ 的概率密度为 $f(x, y)$, 如果反常积分 $\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} g(x, y)f(x, y) dxdy$ 绝对收敛, 则随机变量 $Z = g(X, Y)$ 的数学期望为
$$E(Z) = E[g(X, Y)] = \int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} g(x, y)f(x, y) dxdy. \quad (4.6)$$

# ▶1. 方差及标准差的概念

设 $X$ 是一个随机变量, 若 $E[(X-E(X))^2]$ 存在, 则称之为 $X$ 的**方差**, 记为 $D(X)$, 即
$$D(X) = E\{[X - E(X)]^2\}.$$
由定义可知, $D(X) \ge 0$。
方差的算术平方根 $\sqrt{D(X)}$ 称为 $X$ 的**均方差**或**标准差**, 记作 $\sigma(X)$, 即 $\sigma(X) = \sqrt{D(X)}$。称 $X^* = \frac{X-E(X)}{\sqrt{D(X)}}$ 为 $X$ 的**标准化**随机变量, 此时有 $E(X^*) = 0, D(X^*) = 1$。

# ▶2. 方差的计算公式

$$D(X) = E(X^2) - [E(X)]^2. \quad (4.7)$$

# ▶3. 方差的重要性质

(1) 设 $C$ 是常数, 则 $D(C) = 0$。反之, 从 $D(X) = 0$ 中不能得出 $X$ 为常数的结论。
(2) 设 $X$ 是随机变量, $C$ 是常数, 则有 $D(X + C) = D(X)$。
(3) 设 $X$ 是随机变量, $C$ 是常数, 则有 $D(CX) = C^2 D(X)$。
(4) 设随机变量 $X$ 与 $Y$ 相互独立, 则有 $D(X \pm Y) = D(X) + D(Y)$。
(5) $D(X) = 0$ 的充分必要条件是 $X$ 以概率 $1$ 取常数 $C$, 即 $P\{X = C\} = 1$, 这里 $C = E(X)$。

# (四) 常见随机变量的数学期望和方差

1.  如果 $X \sim (0\text{-}1)$, 即 $P\{X=i\} = p^i(1-p)^{1-i} (i=0, 1)$, 则 $E(X) = p, D(X) = p(1-p)$。
2.  如果 $X \sim B(n, p)$, 则 $E(X) = np, D(X) = np(1-p)$。
3.  如果 $X \sim P(\lambda)$, 则 $E(X) = \lambda, D(X) = \lambda$。
4.  如果 $X$ 服从几何分布, 即 $P\{X = k\} = p(1-p)^{k-1}, k=1, 2, \cdots, 0 < p < 1$, 则
    $E(X) = \frac{1}{p}, \quad D(X) = \frac{1-p}{p^2}$。
5.  如果 $X \sim U(a, b)$, 则 $E(X) = \frac{a+b}{2}, D(X) = \frac{(b-a)^2}{12}$。
6.  如果 $X \sim E(\lambda)$, 则 $E(X) = \frac{1}{\lambda}, D(X) = \frac{1}{\lambda^2}$。
7.  如果 $X \sim N(\mu, \sigma^2)$, 则 $E(X) = \mu, D(X) = \sigma^2$。

**【例4.1】** 假设有10只同等电子元件, 其中有2只废品。装配仪器时, 从这10只元件中任取一只, 如是废品, 则扔掉后再重新任取一只; 如仍是废品, 则扔掉后再任取一只。求在取到正品之前, 已取出的废品只数的数学期望和方差。

**【解】** 设 $X$ 表示在取到正品之前已取出的废品只数, 则 $X$ 的可能取值是0, 1, 2, 其概率分布为
$P\{X = 0\} = \frac{8}{10} = \frac{4}{5}, \quad P\{X = 1\} = \frac{2}{10} \cdot \frac{8}{9} = \frac{8}{45}, \quad P\{X = 2\} = \frac{2}{10} \cdot \frac{1}{9} \cdot 1 = \frac{1}{45}$,
即
$E(X) = 0 \times \frac{4}{5} + 1 \times \frac{8}{45} + 2 \times \frac{1}{45} = \frac{2}{9}$,
$E(X^2) = 0^2 \times \frac{4}{5} + 1^2 \times \frac{8}{45} + 2^2 \times \frac{1}{45} = \frac{4}{15}$,

**【例4.2】** 设随机变量 $X \sim E(1)$, 记 $Y = \max(X, 1)$, 则 $E(Y) =$ ______
(A) 1.
(B) $1+e^{-1}$.
(C) $1-e^{-1}$.
(D) $e^{-1}$.

**【分析】** 如果先去求 $Y$ 的密度 $f_1(y)$, 则计算量很大。直接用随机变量函数的数学期望的定义式(4.4), 有
$E(Y) = E[\max(X, 1)] = \int_{-\infty}^{+\infty} \max(x, 1)f(x)dx,$
其中 $f(x)$ 为指数分布的 $X$ 的密度函数, 且 $f(x) = \begin{cases} e^{-x}, & x>0\\ 0, & x \le 0. \end{cases}$
所以
$E(Y) = \int_{-\infty}^{+\infty} \max(x, 1)f(x)dx = \int_{-\infty}^{0} \max(x, 1) \cdot 0dx + \int_{0}^{+\infty} \max(x, 1) e^{-x}dx$
$= \int_{0}^{1} e^{-x}dx + \int_{1}^{+\infty} xe^{-x}dx = 1-e^{-1}+2e^{-1} = 1+e^{-1}.$
故选(B).

# 二、协方差与相关系数

对于二维随机变量 $(X, Y)$, 其数字特征不仅包括 $X$ 与 $Y$ 的数学期望和方差, 而且还有 $X$ 与 $Y$ 之间相互关系的数字特征——协方差和相关系数。

# (一) 协方差
## ▶1. 协方差的概念

设 $(X, Y)$ 是二维随机变量, 如果 $E[(X-EX)(Y-EY)]$ 存在, 则称之为随机变量 $X$ 与 $Y$ 的**协方差**, 记作 $Cov(X, Y)$, 即 $Cov(X, Y) = E[(X-EX)(Y-EY)]$。

## ▶2. 协方差的计算公式

对任意两个随机变量 $X$ 和 $Y$, 有
(1) $Cov(X, Y) = E(XY) - E(X)E(Y); \quad (4.8)$
(2) $D(X \pm Y) = DX + DY \pm 2Cov(X, Y). \quad (4.9)$

## ▶3. 协方差的性质
(1) $Cov(X, Y) = Cov(Y, X)$;
(2) $Cov(aX, bY) = ab Cov(X, Y)$ ($a, b$ 是常数);
(3) $Cov(X_1+X_2, Y) = Cov(X_1, Y) + Cov(X_2, Y)$。

# (二) 相关系数
## ▶1. 相关系数的概念

如果 $X, Y$ 的方差都存在且都不等于零, 则称 $\frac{Cov(X, Y)}{\sqrt{DX}\sqrt{DY}}$ 为随机变量 $X$ 与 $Y$ 的**相关系数**, 记为 $\rho_{XY}$, 即
$$\rho_{XY} = \frac{Cov(X, Y)}{\sqrt{DX}\sqrt{DY}}.$$

## ▶2. 相关系数的性质
(1) $|\rho_{XY}| \le 1$;
(2) $|\rho_{XY}| = 1$ 的充分必要条件是, 存在常数 $a, b$, 使 $P\{Y = aX + b\} = 1$。

## ▶3. 随机变量 $X$ 与 $Y$ 不相关

如果随机变量 $X$ 与 $Y$ 的相关系数 $\rho_{XY} = 0$ (即 $Cov(X, Y) = 0$), 则称 $X$ 与 $Y$ **不相关**。关于随机变量 $X$ 与 $Y$ 的独立性与相关性, 有如下结论:
(1) 若随机变量 $X$ 与 $Y$ 独立, 则 $X$ 与 $Y$ 一定不相关; 但是如果若 $X$ 与 $Y$ 不相关, 则 $X$ 与 $Y$ 不一定独立。
(2) 若随机变量 $X$ 与 $Y$ 的联合分布是二维正态分布, 则 $X$ 与 $Y$ 独立的充要条件是 $X$ 与 $Y$ 不相关。
(3) 若随机变量 $X$ 与 $Y$ 都服从0-1分布, 则 $X$ 与 $Y$ 独立的充要条件是 $X$ 与 $Y$ 不相关。

## ▶4. 对于随机变量 $X$ 与 $Y$, 下面四个结论是等价的
(1) $Cov(X, Y) = 0$;
(2) $X$ 与 $Y$ 不相关;
(3) $EXY = EXEY$;
(4) $D(X+Y) = DX + DY$。

(B) $P\{Y=2X-1\} = 1$.
(C) $P\{Y=-2X+1\} = 1$.
(D) $P\{Y=2X+1\} = 1$.

**【分析】** 由于 $X$ 与 $Y$ 的相关系数 $\rho_{XY}=1 > 0$, 因此 $P\{Y=aX+b\} = 1$, 且 $a>0$。又因为 $Y \sim N(1,4), X \sim N(0,1)$, 所以 $EX=0, EY=1$。而 $EY = E(aX+b) = b \Rightarrow b=1$。即应选(D)。

**【例4.9】** 已知随机变量 $X$ 与 $Y$ 有相同的不为零的方差, 则 $X$ 与 $Y$ 相关系数 $\rho=1$ 的充要条件是
(A) $Cov(X+Y, X) = 0$.
(B) $Cov(X+Y, Y) = 0$.
(C) $Cov(X+Y, X-Y) = 0$.
(D) $Cov(X-Y, X) = 0$.

**【分析】** 直接用定义通过计算确定正确选项。已知 $DX = DY = \sigma^2 > 0$, 则
$\rho = \frac{Cov(X, Y)}{\sqrt{DX}\sqrt{DY}} = \frac{Cov(X, Y)}{DX} = \frac{Cov(X, Y)}{Cov(X, X)} = 1 \Leftrightarrow Cov(X, Y) = Cov(X, X)$
$\Leftrightarrow Cov(X, Y-X) = 0$
$\Leftrightarrow Cov(X-Y, X) = 0$.
故选(D)。其余选项均不正确，这是因为当 $DX = DY$ 时，
$Cov(X+Y, X) = 0 \Leftrightarrow Cov(X, X) = -Cov(X, Y) \Rightarrow \rho = \frac{Cov(X, Y)}{\sqrt{DX}\sqrt{DY}} = \frac{-Cov(X, Y)}{DX} = -1$;
$Cov(X+Y, Y) = 0 \Leftrightarrow Cov(X, Y) = -Cov(Y, Y) \Rightarrow \rho = \frac{Cov(X, Y)}{\sqrt{DX}\sqrt{DY}} = \frac{-Cov(Y, Y)}{DY} = -1$;
$Cov(X+Y, X-Y) = 0 \Leftrightarrow Cov(X, X) = Cov(Y, Y)$, 即 $DX = DY$.

### 三、随机变量的矩
设 $(X, Y)$ 是二维随机变量, 如果 $E(X^k Y^l)$ 存在, 则称 $E(X^k)$ ($k=1,2,\cdots$) 为 $X$ 的 $k$ 阶原点矩; 称 $E(X-EX)^k$ ($k=2,3,\cdots$) 为 $X$ 的 $k$ 阶中心矩; 称 $E(X^k Y^l)$ ($k,l=1,2,\cdots$) 为 $X$ 与 $Y$ 的 $k+l$ 阶混合原点矩; 称 $E[(X-EX)^k(Y-EY)^l]$ ($k,l=1,2,\cdots$) 为 $X$ 与 $Y$ 的 $k+l$ 阶混合中心矩。
从上述定义看出：数学期望 $EX$ 是 $X$ 的一阶原点矩，方差 $DX$ 是 $X$ 的二阶中心矩，协方差 $Cov(X, Y)$ 是 $X$ 与 $Y$ 的混合二阶中心矩。

从而有 $E(Y) = E(Z) = \frac{4}{3}$，于是

**【例4.12】** 已知随机变量 $X$ 的概率密度为 $f(x) = A\mathrm{e}^{(Bx-x^2)} \quad (-\infty < x < +\infty)$，且 $EX = 2D(X)$，
试求：(I) 常数 $A, B$ 之值；(II) $E(X^2+\mathrm{e}^X)$；(III) $Y = |\sqrt{2}(X-1)|$ 的分布函数 $F(y)$。

**【分析】** $f(x) = A\mathrm{e}^{(Bx-x^2)} = A\mathrm{e}^{-\frac{x^2}{2}-(x-\frac{B}{2})^2} = A\mathrm{e}^{\frac{B^2}{4}}\mathrm{e}^{-(x-\frac{B}{2})^2}$，可以将 $f(x)$ 看成正态分布 $N\left(\frac{B}{2}, \frac{1}{2}\right)$ 的概率密度函数。

**【解】**
(I) 由 $X \sim N\left(\frac{B}{2}, \frac{1}{2}\right)$ 且 $E(X) = 2D(X)$，得到 $E(X) = \frac{B}{2} = 2D(X) = 1$，即 $B=2$。
而 $A\mathrm{e}^{\frac{1}{4}} = \frac{1}{\sqrt{2\pi}\sigma} = \frac{1}{\sqrt{\pi} \cdot \sqrt{\frac{1}{2}}} = \frac{1}{\sqrt{\pi}}$，于是 $A = \frac{\mathrm{e}^{-\frac{1}{4}}}{\sqrt{\pi}}$，从而 $f(x) = \frac{1}{\sqrt{\pi}}\mathrm{e}^{-(x-1)^2}$。

(II) $E(X^2+\mathrm{e}^X) = E(X^2) + E(\mathrm{e}^X)$。而
$E(X^2) = D(X) + [E(X)]^2 = \frac{1}{2} + 1 = \frac{3}{2}$,

$E(\mathrm{e}^X) = \int_{-\infty}^{+\infty} \mathrm{e}^t f(t)dt = \int_{-\infty}^{+\infty} \mathrm{e}^t \frac{1}{\sqrt{\pi}} \mathrm{e}^{-(t-1)^2} dt = \frac{1}{\sqrt{\pi}} \int_{-\infty}^{+\infty} \mathrm{e}^{-t^2+3t-1} dt$
$= \frac{1}{\sqrt{\pi}} \int_{-\infty}^{+\infty} \mathrm{e}^{-(t-\frac{3}{2})^2+\frac{9}{4}-1} dt = \mathrm{e}^{\frac{5}{4}} \int_{-\infty}^{+\infty} \frac{1}{\sqrt{\pi}} \mathrm{e}^{-(t-\frac{3}{2})^2} dt = \mathrm{e}^{\frac{5}{4}}$
所以 $E(X^2+\mathrm{e}^X) = \frac{3}{2} + \mathrm{e}^{\frac{5}{4}}$。

(III) 由于 $X \sim N\left(1, \frac{1}{2}\right)$，故 $(X-1) \sim N\left(0, \frac{1}{2}\right)$，$\sqrt{2}(X-1) \sim N(0,1)$。
显然，当 $y < 0$ 时，$F(y) = 0$；当 $y \geqslant 0$ 时，
$F(y) = P\{Y \leqslant y\} = P\{|\sqrt{2}(X-1)| \leqslant y\} = P\{-y \leqslant \sqrt{2}(X-1) \leqslant y\}$
$= \int_{-y}^{y} \frac{1}{\sqrt{2\pi}} \mathrm{e}^{-\frac{t^2}{2}} dt = 2 \int_{0}^{y} \frac{1}{\sqrt{2\pi}} \mathrm{e}^{-\frac{t^2}{2}} dt = 2\Phi(y) - 1$
故 $F(y) = \begin{cases} 0, & y < 0 \\ 2\Phi(y) - 1, & y \geqslant 0 \end{cases}$
其中 $\Phi(y)$ 为标准正态分布的分布函数。

**【例4.13】** 投篮测试规则为每人最多投三次，投中为止，且第 $i$ 次投中得分为 $(4-i)$ 分，$i=1,2,3$。若三次均未投中不得分，假设某人投篮测试中投篮的平均次数为 $1.56$ 次。
(I) 求该人投篮的命中率； (II) 求该人投篮的平均得分。

**【解】**
(I) 设该投球员投篮次数为 $X$，投篮得分为 $Y$；每次投篮命中率为 $p (0 < p < 1)$，则 $X$ 的概率分布为
$P\{X=1\} = p, \quad P\{X=2\} = pq, \quad P\{X=3\} = q^2$,
$EX = p + 2pq + 3q^2 = p + 2p(1-p) + 3(1-p)^2 = p^2 - 3p + 3$。
依题意 $p^2 - 3p + 3 = 1.56$，即 $p^2 - 3p + 1.44 = 0$。
解得 $p = 0.6$ ($p=2.4$ 不合题意，舍去)。

(II) $Y$ 可以取 $0, 1, 2, 3$ 四个可能值，且
$P\{Y=0\} = q^3 = 0.4^3 = 0.064, \quad P\{Y=1\} = pq^2 = 0.6 \times 0.4^2 = 0.096$,
$P\{Y=2\} = pq = 0.6 \times 0.4 = 0.24, \quad P\{Y=3\} = p = 0.6$
于是 $EY = \sum_{i=0}^{3} i P\{Y=i\} = 2.376 (\text{分})$。

> **评注**
> ① 求命中率 $p$ 就是求随机变量 $X$ 分布律的未知参数问题，这可以根据题意列出一个以 $p$ 为未知量的方程解决，但要注意作为命中率 $p$ 是不能大于 $1$ 的，故应舍去 $p=2.4$ 这一解。
> ② 求一个离散型随机变量分布律，首先应明确其全部可能取值，然后计算取各相应值的概率，前者一般是显而易见的，如本例中的投篮次数、投篮得分，而计算概率有时比较复杂。
> ③ 本例中若误认为 $P\{X=3\} = pq^2$，则会出现 $\sum_{i=1}^3 P\{X=i\} \neq 1$ 的矛盾。这是由于投篮测试规则限定每人最多可投三次，一位投球员投了三次，仅表明他前面两次未投中，不能说明他第三次是投中还是没有投中。而事件 "$Y=1$"，则表示投球员投了三次且第三次投中了，其概率为 $pq^2$。

**【例4.14】** 已知随机变量 $X_1$ 与 $X_2$ 相互独立且分别服从参数为 $\lambda_1, \lambda_2$ 的泊松分布，$P\{X_1+X_2 > 0\} = 1-\mathrm{e}^{-1}$，则 $E(X_1+X_2)^2 = $ ______。

$E(X_1+X_2)^2 = E(X_1^2 + 2X_1X_2 + X_2^2) = EX_1^2 + 2EX_1EX_2 + EX_2^2$
$= \lambda_1 + \lambda_1^2 + 2\lambda_1\lambda_2 + \lambda_2 + \lambda_2^2 = \lambda_1 + \lambda_2 + (\lambda_1 + \lambda_2)^2$。

为求得最终结果我们需要由已知条件求得 $\lambda_1 + \lambda_2$。因为
$P\{X_1+X_2 > 0\} = 1 - P\{X_1+X_2 \leqslant 0\} = 1 - P\{X_1+X_2 = 0\}$
$= 1 - P\{X_1=0, X_2=0\} = 1 - P\{X_1=0\}P\{X_2=0\}$

**【例4.15】** 已知 $(X, Y)$ 在以点 $(0,0), (1,0), (1,1)$ 为顶点的三角形区域上服从均匀分布，对 $(X, Y)$ 作 $4$ 次独立重复观察，观察值 $X+Y$ 不超过 $1$ 出现的次数为 $Z$，则 $EZ^2 = $ ______。

$f(x, y) = \begin{cases} 2, & 0 < y < x < 1 \\ 0, & \text{其他} \end{cases}$

$p = P(A) = P\{X+Y \leqslant 1\} = \iint_{x+y \leqslant 1} f(x, y) \mathrm{d}x\mathrm{d}y$

**【例4.17】** 设二维随机变量 $(X, Y)$ 的联合概率密度为

$f_Z(z) = F'(z) = \begin{cases} \frac{1}{2\sigma^2} \mathrm{e}^{-\frac{z}{2\sigma^2}}, & z > 0 \\ 0, & z \leqslant 0 \end{cases}$

由此可以看出，$Z$ 服从参数为 $\frac{1}{2\sigma^2}$ 的指数分布。
(II) 方法 1° 由 (I) 的结果 (指数分布) 可知，$EZ = 2\sigma^2, DZ = 4\sigma^4$。

**【例4.18】** 设随机变量 $X_1, X_2, \cdots, X_n$ 相互独立，且都服从数学期望为 $1$ 的指数分布，求 $Z = \min\{X_1, X_2, \cdots, X_n\}$ 的数学期望和方差。

**【解】** $X_i (i=1,2,\cdots,n)$ 的分布函数为
$F(x) = \begin{cases} 1 - \mathrm{e}^{-x}, & x > 0 \\ 0, & \text{ 其他} \end{cases}$
由于诸 $X_i (i=1,2,\cdots,n)$ 相互独立，则 $Z = \min\{X_1, X_2, \cdots, X_n\}$ 的分布函数与概率密度分别为
$F_Z(z) = 1 - [1 - F(z)]^n = \begin{cases} 1 - (1 - \mathrm{e}^{-z})^n, & z > 0 \\ 0, & \text{ 其他} \end{cases}, \quad f_Z(z) = \begin{cases} n\mathrm{e}^{-nz}, & z > 0 \\ 0, & \text{ 其他} \end{cases}$
由于
$E(Z) = \int_0^{+\infty} z n \mathrm{e}^{-nz} \mathrm{d}z = \frac{1}{n} \Gamma(2) = \frac{1}{n}$,
$E(Z^2) = \int_0^{+\infty} z^2 n \mathrm{e}^{-nz} \mathrm{d}z = \frac{1}{n^2} \Gamma(3) = \frac{2}{n^2}$,
于是
$D(Z) = E(Z^2) - [E(Z)]^2 = \frac{1}{n^2}$。

> **评注**
> ① 由 $Z$ 服从参数为 $n$ 的指数分布可知，$EZ = \frac{1}{n}, DZ = \frac{1}{n^2}$。
> ② 该题在求解过程中用了 $\Gamma$ 函数，它在概率统计的计算中提供了很多方便，希望读者能掌握 $\Gamma$ 函数的定义与简单性质。
> 定义 $\Gamma(\alpha) = \int_0^{+\infty} x^{\alpha-1}\mathrm{e}^{-x} \mathrm{d}x (\alpha > 0)$。
> 性质 $\Gamma(\alpha+1) = \alpha\Gamma(\alpha), \quad \Gamma(1) = 1, \quad \Gamma(n+1) = n!, \quad \Gamma\left(\frac{1}{2}\right) = \sqrt{\pi}$。

$P\{X_i=0\} = \left(1 - \frac{1}{m}\right)^n, \quad P\{X_i=1\} = 1 - \left(1 - \frac{1}{m}\right)^n$.
$EX = E\left(\sum_{i=1}^m X_i\right) = \sum_{i=1}^m E X_i = m\left[1 - \left(1-\frac{1}{m}\right)^n\right]$.

> **评注**
> 求一个随机变量期望和方差主要有 $4$ 种方法：
> <u>方法 1°</u> 直接用期望和方差定义。
> <u>方法 2°</u> 应用期望与方差的性质和随机变量函数的期望公式。
> <u>方法 3°</u> 应用常见分布的期望与方差公式。
> <u>方法 4°</u> 将一个随机变量分解求期望和方差 (如本例)。比如，将一个随机变量 $X$ 表示为一些简单随机变量 $X_1, \cdots, X_n$ 之和，通过这些简单随机变量 $X_i$ 的期望 $EX_i$、方差 $DX_i$、协方差 $Cov(X_i, X_j)$，再应用期望与方差的性质计算出所要求的随机变量 $X$ 的期望与方差，即 $X = \sum_{i=1}^n X_i$，则有
> $EX = E\left(\sum_{i=1}^n X_i\right) = \sum_{i=1}^n EX_i; \quad DX = D\left(\sum_{i=1}^n X_i\right) = \sum_{i=1}^n DX_i + 2 \sum_{1 \leqslant i < j \leqslant n} Cov(X_i, X_j)$。
