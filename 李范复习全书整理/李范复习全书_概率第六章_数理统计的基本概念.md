# 第六章 数理统计的基本概念

## 知识结构网络图
- 数理统计的基本概念
  - 总体：随机变量 $X, Y, \cdots$
  - 样本
    - **定义**：$n$ 个相互独立且与总体同分布的随机变量
    - 容量为 $n$ 的简单随机样本：样本与样本值
    - **统计量** $g(X_1, \cdots, X_n)$
      - 常用统计量及其性质：样本均值 $\bar{X}$，样本方差 $S^2$，样本 $k$ 阶矩
      - **抽样分布**
        - $\chi^2$ 分布，$t$ 分布，$F$ 分布典型模式、性质及其分位数
        - 单个正态总体：$\bar{X}, S^2$ 的独立性及其分布
        - 两个正态总体：$\bar{X} - \bar{Y}$，$\frac{S_1^2}{S_2^2}$ 的分布及 $\bar{X}, \bar{Y}, S_1^2, S_2^2$ 相互独立
        - 非正态总体：$\frac{\sqrt{n}(\bar{X} - \mu)}{\sigma}$ 以 $N(0,1)$ 为其极限分布

## 内容概要与重难点提示
统计学的核心问题是由样本推断总体。统计量是样本的函数，其选择和运用在统计推断中占据核心地位。我们所涉及的统计量主要是样本的数字特征（如样本均值、样本方差、样本原点矩与样本中心矩等）。

统计量的分布称为抽样分布。最常用的有 $\chi^2$ 分布，$t$ 分布和 $F$ 分布，它们都是正态随机变量函数的分布。

由于在区间估计与假设检验中多涉及正态分布总体，因此考生还应掌握正态总体的抽样分布，它们是样本均值、样本方差、样本矩、样本均值差及样本方差比的抽样分布。

## 考核知识点讲解

### 一、总体与样本

#### （一）总体、简单随机样本、抽样的概念
1. 在数理统计中所研究对象的某项数量指标 $X$ 取值的全体称为**总体**，$X$ 是一个随机变量。$X$ 的分布函数和数字特征分别称为总体的分布函数和数字特征。总体中的每个元素称为**个体**，每个个体是一

<!-- 物理页563 印刷页553 -->
个实数。

2. $n$ 个相互独立且与总体 $X$（设 $X$ 的分布函数为 $F(x)$）同分布的随机变量 $X_1, X_2, \cdots, X_n$ 称为来自总体 $X$ 或来自分布函数 $F$ 的**简单随机样本**，简称为样本，$n$ 称为样本容量；设 $x_1, x_2, \cdots, x_n$ 分别是 $X_1, X_2, \cdots, X_n$ 的观测值，则称 $x_1, x_2, \cdots, x_n$ 为**样本值**，又称为总体 $X$ 的 $n$ 个独立的观测值。简单地说，样本指一组随机变量，样本值指一组具体的统计数据，样本容量指观测值或数据个数。
3. 对于总体 $X$ 的 $n$ 次独立重复观测，称为来自总体 $X$ 的 $n$ 次简单随机抽样。

#### （二）简单随机样本的概率分布
1. 如果总体 $X$ 的分布函数为 $F(x)$，$X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的简单随机样本，则随机变量 $X_1, X_2, \cdots, X_n$ 的联合分布函数为
$$F(x_1, x_2, \cdots, x_n) = \prod_{i=1}^n F(x_i), x_i \in R (i=1, 2, \cdots, n)$$
2. 如果总体 $X$ 的概率密度为 $f(x)$，则样本 $X_1, X_2, \cdots, X_n$ 的联合概率密度为
$$f(x_1, x_2, \cdots, x_n) = \prod_{i=1}^n f(x_i), x_i \in R (i=1, 2, \cdots, n)$$
3. 如果总体 $X$ 的概率分布为 $P\{X=a_j\} = p_j (j=1, 2, \cdots)$，则样本 $X_1, X_2, \cdots, X_n$ 的联合概率分布为
$$P\{X_1=x_1, X_2=x_2, \cdots, X_n=x_n\} = \prod_{i=1}^n P\{X_i=x_i\}$$
其中 $x_i$ 取 $a_1, a_2, \cdots$ 中的某一个数。

**【例6.1】** 设总体 $X \sim E(\lambda)$，则来自总体 $X$ 的简单随机样本 $X_1, X_2, \cdots, X_n$ 的联合概率密度 $f(x_1, x_2, \cdots, x_n) = $ _______。
**【分析】** 总体 $X$ 的概率密度 $f(x) = \begin{cases} \lambda e^{-\lambda x}, & x>0 \\ 0, & x \leq 0 \end{cases}$，由于 $X_1, X_2, \cdots, X_n$ 相互独立，且与总体 $X$ 服从同一指数分布，因此
$$f(x_1, x_2, \cdots, x_n) = \prod_{i=1}^n f(x_i) = \begin{cases} \lambda^n e^{-\lambda \sum_{i=1}^n x_i}, & x_i > 0 (i=1, 2, \cdots, n) \\ 0, & \text{其他} \end{cases}$$

**【例6.2】** 设总体 $X \sim P(\lambda)$，则来自总体 $X$ 的简单随机样本 $X_1, X_2, \cdots, X_n$ 的样本均值 $\bar{X}$ 的概率分布为 _______。
**【分析】** 由泊松分布的可加性可知，当 $X_1, X_2$ 独立时，$X_1+X_2 \sim P(2\lambda)$。继而有 $X_1, X_2, \cdots, X_n$ 独立同为 $P(\lambda)$ 分布时，$\sum_{i=1}^n X_i = n\bar{X} \sim P(n\lambda)$。于是，对任意 $n \geqslant 1$，$n\bar{X}$ 的概率分布为
$$P\{n\bar{X} = k\} = P\left\{\sum_{i=1}^n X_i = k\right\} = \frac{(n\lambda)^k e^{-n\lambda}}{k!}, k=0, 1, 2, \cdots$$
而 $P\{n\bar{X} = k\} = P\left\{\bar{X} = \frac{k}{n}\right\}$，所以
$$P\left\{\bar{X} = \frac{k}{n}\right\} = \frac{(n\lambda)^k e^{-n\lambda}}{k!}, k=0, 1, 2, \cdots$$

## 二、统计量

### （一）统计量的概念
设 $X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的一个样本，$g(X_1, X_2, \cdots, X_n)$ 是 $X_1, X_2, \cdots, X_n$ 的函数。若 $g$ 中不含有任何未知参数，则称 $g(X_1, X_2, \cdots, X_n)$ 为样本 $(X_1, X_2, \cdots, X_n)$ 的一个**统计量**。设 $x_1, x_2, \cdots, x_n$ 是相应于样本 $X_1, X_2, \cdots, X_n$ 的样本值，则称 $g(x_1, x_2, \cdots, x_n)$ 是 $g(X_1, X_2, \cdots, X_n)$ 的**观测值**。
统计量是样本 $(X_1, X_2, \cdots, X_n)$ 的函数。统计量不依赖于任何未知参数。作为随机变量的函数，统计量也是随机变量。样本的数字特征是最常用的统计量。

### （二）常用统计量（样本矩）
设 $X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的简单随机样本，则

►1. **样本均值**：$\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$

►2. **样本方差**：$S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2 = \frac{1}{n-1} \left(\sum_{i=1}^n X_i^2 - n\bar{X}^2\right)$
样本**标准差**：$S = \sqrt{\frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2}$

**[注]** 如果总体 $X$（不管服从什么分布，只要其均值和方差存在）具有数学期望 $E(X) = \mu$ 和方差 $D(X) = \sigma^2$，则总有
$$E(\bar{X}) = E(X) = \mu, \quad D(\bar{X}) = \frac{D(X)}{n} = \frac{\sigma^2}{n}, \quad E(S^2) = D(X) = \sigma^2$$

►3. **样本 $k$ 阶原点矩**：$A_k = \frac{1}{n} \sum_{i=1}^n X_i^k, k=1, 2, \cdots$

►4. **样本 $k$ 阶中心矩**：$B_k = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^k, k=2, 3, \cdots$

**[注]**
① $B_2 = \frac{n-1}{n} S^2 < S^2$。
② 如果总体 $X$ 的 $k$ 阶原点矩 $E(X^k) = \mu_k (k=1, 2, \cdots)$ 存在，则当 $n \to \infty$ 时，有
$$A_k = \frac{1}{n} \sum_{i=1}^n X_i^k \xrightarrow{P} \mu_k, k=1, 2, \cdots$$

## 三、抽样分布
统计量的分布称为**抽样分布**。注意：抽样分布可能含有未知参数；有时（当样本函数含有未知参数，但其分布不依赖于未知参数时）将含有未知参数的样本函数的分布也称为抽样分布。

### （一）来自正态总体的三个常用统计量的分布

►1. **$\chi^2$ 分布**
$\chi^2$ 分布是一种非负连续型随机变量的分布，其密度函数的图形位于第一象限，峰值向左偏，随着 $n$

<!-- 物理页565 印刷页555 -->
的增大，峰值向右移动。

(1) **典型模式** 设 $X_1, X_2, \cdots, X_n$ 相互独立，都服从标准正态分布 $N(0,1)$，则称统计量
$$\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2 = \sum_{i=1}^n X_i^2$$
服从自由度为 $n$ 的 $\chi^2$ 分布，记作 $\chi^2 \sim \chi^2(n)$。此处，自由度是指上式右端包含的独立变量的个数。
(2) **$\chi^2$ 分布的分位点** 对于给定的 $\alpha (0 < \alpha < 1)$，称满足条件
$$P\{\chi^2 > \chi_{\alpha}^2(n)\} = \int_{\chi_{\alpha}^2(n)}^{+\infty} f(t) dt = \alpha$$
（$f(t)$ 为 $\chi^2(n)$ 分布的概率密度函数）的点 $\chi_{\alpha}^2(n)$ 为 $\chi^2(n)$ 分布的上 $\alpha$ 分位点（图6.1）。
(3) **$\chi^2$ 分布的性质**
1° $\chi^2$ 分布的数学期望和方差分别为 $E(\chi^2(n)) = n, \quad D(\chi^2(n)) = 2n$。
2° $\chi^2$ 分布具有可加性：设 $\chi_1^2 \sim \chi^2(n_1), \chi_2^2 \sim \chi^2(n_2)$，且 $\chi_1^2, \chi_2^2$ 相互独立，则有 $\chi_1^2 + \chi_2^2 \sim \chi^2(n_1 + n_2)$。

►2. **$t$ 分布**
$t$ 分布是一种连续型随机变量的分布，其密度函数的图形关于 $y$ 轴对称，形状与标准正态分布曲线相类似。
(1) **典型模式** 设 $X \sim N(0,1), Y \sim \chi^2(n)$，且 $X$ 与 $Y$ 相互独立，则称随机变量
$$t = \frac{X}{\sqrt{Y/n}}$$
服从自由度为 $n$ 的 $t$ 分布，记作 $t \sim t(n)$（图6.2）。
(2) **$t$ 分布的分位点** 对于给定的 $\alpha (0 < \alpha < 1)$，称满足条件
$$P\{|t| > t_{\alpha}(n)\} = \int_{t_{\alpha}(n)}^{+\infty} f(t) dt = \alpha$$
（$f(t)$ 为 $t(n)$ 分布的概率密度函数）的点 $t_{\alpha}(n)$ 为 $t(n)$ 分布的上 $\alpha$ 分位点（图6.2）。
由 $t$ 分布上 $\alpha$ 分位点的定义及 $f(t)$ 图形的对称性知 $t_{1-\alpha}(n) = -t_{\alpha}(n)$。
(3) **$t$ 分布的性质** $t(n)$ 分布的概率密度函数 $f(t)$ 是偶函数，且有
$$\lim_{n \to \infty} f(t) = \frac{1}{\sqrt{2\pi}} e^{-t^2/2}$$
可见，当 $n$ 足够大时 $t$ 分布近似于 $N(0,1)$ 分布，但对于较小的 $n$，$t$ 分布与 $N(0,1)$ 分布相差较大。
若 $t \sim t(n)$，则 $t^2 \sim F(1, n)$。

►3. **$F$ 分布**
$F$ 分布是一种非负连续型随机变量 $X$ 的分布，其密度函数含有两个参数 $n_1, n_2$，函数曲线的形状与 $\chi^2$ 分布相似。
(1) **典型模式** 设 $X \sim \chi^2(n_1), Y \sim \chi^2(n_2)$，且 $X$ 与 $Y$ 相互独立，则称随机变量
$$F = \frac{X/n_1}{Y/n_2}$$
服从自由度为 $(n_1, n_2)$ 的 $F$ 分布，记作 $F \sim F(n_1, n_2)$。

(2) **$F$ 分布的分位点** 对于给定的 $\alpha (0 < \alpha < 1)$，称满足条件
$$P\{F > F_{\alpha}(n_1, n_2)\} = \int_{F_{\alpha}(n_1, n_2)}^{+\infty} f(t) dt = \alpha$$
（$f(t)$ 为 $F(n_1, n_2)$ 分布的概率密度函数）的点 $F_{\alpha}(n_1, n_2)$ 为 $F(n_1, n_2)$ 分布的上 $\alpha$ 分位点（图6.3）。
(3) **$F$ 分布的性质**
1° 如果 $F \sim F(n_1, n_2)$，则 $\frac{1}{F} \sim F(n_2, n_1)$；
2° $F_{1-\alpha}(n_1, n_2) = \frac{1}{F_{\alpha}(n_2, n_1)}$。

**【例6.3】** 设随机变量 $X$ 服从 $F(3,4)$ 分布，对给定的 $\alpha (0 < \alpha < 1)$，数 $F_{\alpha}(3,4)$ 满足 $P\{X > F_{\alpha}(3,4)\} = \alpha$。若 $P\{X \leq x\} = 1 - \alpha$，则 $x = $ ______。
(A) $\frac{1}{F_{1-\alpha}(4,3)}$ (B) $\frac{1}{F_{\alpha}(3,4)}$ (C) $F_{\alpha}(4,3)$ (D) $F_{1-\alpha}(4,3)$

**【分析一】** 因 $X \sim F(3,4)$，故 $\frac{1}{X} \sim F(4,3)$。又
$$1 - \alpha = P\{X \leq x\} = P\{X < x\} = P\left\{\frac{1}{X} > \frac{1}{x}\right\}$$
所以 $\frac{1}{x} = F_{1-\alpha}(4,3)$，即 $x = \frac{1}{F_{1-\alpha}(4,3)}$。因此选 (A)。

**【分析二】** 由 $P\{X \leq x\} = 1 - \alpha$ 可知，$P\{X > x\} = \alpha$，即 $x = F_{\alpha}(3,4)$。又由 $F_{1-\alpha}(n_1, n_2) = \frac{1}{F_{\alpha}(n_2, n_1)}$ 可知，$F_{\alpha}(3,4) = \frac{1}{F_{1-\alpha}(4,3)}$。故选 (A)。

**【例6.4】** 已知 $\chi^2 \sim \chi^2(n)$，则 $E(\chi^2) = $ _______。
**【分析】** 由 $\chi^2$ 分布的典型模式 $\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2 = \sum_{i=1}^n X_i^2$ 知，$E(\chi^2) = \sum_{i=1}^n E(X_i^2)$。而 $X_i \sim N(0,1)$，且 $X_i$ 相互独立，由于 $E(X_i^2) = D(X_i) + [E(X_i)]^2 = 1 + 0 = 1$，所以
$$E(\chi^2) = \sum_{i=1}^n E(X_i^2) = n$$

**【例6.5】** 已知 $X_1, X_2, X_3$ 相互独立且服从 $N(0, \sigma^2)$，则 $\sqrt{\frac{2}{3}} \frac{X_1 + X_2 + X_3}{|X_2 - X_3|}$ 服从的分布及参数为 _______。
**【分析】** 记 $Y_1 = X_2 + X_3, Y_2 = X_2 - X_3$，则 $Y_1 \sim N(0, 2\sigma^2), Y_2 \sim N(0, 2\sigma^2)$。由于
$$\text{Cov}(Y_1, Y_2) = E(Y_1 Y_2) - E(Y_1) E(Y_2) = E[(X_2 + X_3)(X_2 - X_3)] = E(X_2^2) - E(X_3^2) = \sigma^2 - \sigma^2 = 0$$
所以 $Y_1$ 与 $Y_2$ 不相关，而正态分布下不相关即独立，且 $Y_2$ 与 $X_1$ 独立。
又由 $X_1 + X_2 + X_3 = X_1 + Y_1 \sim N(0, 3\sigma^2)$，
可知 $\frac{1}{\sigma\sqrt{3}}(X_1 + X_2 + X_3) \sim N(0,1)$，$\left(\frac{X_2 - X_3}{\sqrt{2}\sigma}\right)^2 \sim \chi^2(1)$，且 $X_1 + X_2 + X_3$ 与 $X_2 - X_3$ 相互独立。于是按 $t$ 分布定义有
$$\sqrt{\frac{2}{3}} \frac{X_1 + X_2 + X_3}{|X_2 - X_3|} \sim t(1)$$

### （二）正态总体的样本均值与样本方差的分布

►1. **单个正态总体**
设 $X \sim N(\mu, \sigma^2)$，$X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的简单随机样本，$\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$ 与 $S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2$ 分别为相应的样本均值和样本方差。
(1) **样本均值的分布**：
$$\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right), \quad \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} = \frac{\sqrt{n}(\bar{X} - \mu)}{\sigma} \sim N(0,1); \quad \frac{\bar{X} - \mu}{S/\sqrt{n}} = \frac{\sqrt{n}(\bar{X} - \mu)}{S} \sim t(n-1).$$
(2) **样本方差的分布**：
$$\frac{1}{\sigma^2} \sum_{i=1}^n (X_i - \mu)^2 \sim \chi^2(n), \quad \frac{(n-1)S^2}{\sigma^2} = \sum_{i=1}^n \left(\frac{X_i - \bar{X}}{\sigma}\right)^2 \sim \chi^2(n-1).$$
(3) $\bar{X}$ 与 $S^2$ 相互独立（这是正态总体特有的性质）。

►2. **两个正态总体**

### （三）$X_{(n)} = \max(X_1, X_2, \cdots, X_n)$ 和 $X_{(1)} = \min(X_1, X_2, \cdots, X_n)$ 的分布

设总体 $X$ 的分布函数为 $F(x)$，$X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的简单随机样本，则统计量 $X_{(n)} = \max(X_1, X_2, \cdots, X_n)$ 和 $X_{(1)} = \min(X_1, X_2, \cdots, X_n)$ 的分布函数分别为
$$F_{\max}(x) = P\{\max(X_1, X_2, \cdots, X_n) \leqslant x\} = [F(x)]^n,$$
$$F_{\min}(x) = P\{\min(X_1, X_2, \cdots, X_n) \leqslant x\} = 1 - [1 - F(x)]^n.$$

**【例6.7】** 设 $X_1, X_2, X_3, X_4$ 是来自正态总体 $N(0, 2^2)$ 的简单随机样本，记 $Y = a(X_1 - 2X_2)^2 + b(3X_3 - 4X_4)^2$，其中 $a, b$ 为常数。已知 $Y \sim \chi^2(n)$，则
(A) $n$ 必为 2.
(B) $n$ 必为 4.
(C) $n$ 为 1 或 2.
(D) $n$ 为 2 或 4.

**【分析】** 依题意 $X_i \sim N(0, 2^2)$ 且相互独立，所以 $X_1 - 2X_2 \sim N(0, 20)$，$\frac{X_1 - 2X_2}{\sqrt{20}} \sim N(0, 1)$；$3X_3 - 4X_4 \sim N(0, 100)$，$\frac{3X_3 - 4X_4}{10} \sim N(0, 1)$ 且它们相互独立。由 $\chi^2$ 分布的典型模式及性质知
1. 当 $a = \frac{1}{20}, b = \frac{1}{100}$ 时，$Y \sim \chi^2(2)$；
2. 当 $a = \frac{1}{20}, b = 0$，或 $a = 0, b = \frac{1}{100}$ 时，$Y \sim \chi^2(1)$。
由上可知，$n = 1$ 或 2，即应选 (C)。

**【例6.8】** 设 $X_1, X_2, \cdots, X_n$ 是来自标准正态总体 $N(0, 1)$ 的简单随机样本，其均值和方差分别为 $\bar{X}$ 和 $S^2$，记 $T = \bar{X} + S^2$。试求 $E(T)$ 与 $E(T^2)$ 的值。

**【解】** 由正态总体的性质知，$\bar{X}$ 与 $S^2$ 相互独立；由样本数字特征的性质知，$E(\bar{X}) = E(X) = 0$，$D(\bar{X}) = \frac{D(X)}{n} = \frac{1}{n}$，$E(S^2) = D(X) = 1$；由正态总体的样本方差的分布知，$(n-1)S^2 \sim \chi^2(n-1)$；由 $\chi^2$ 分布的性质知，$D[\chi^2(n-1)] = 2(n-1)$，从而 $D[(n-1)S^2] = (n-1)^2 D(S^2) = 2(n-1)$，即 $D(S^2) = \frac{2}{n-1}$。于是
$$\begin{aligned}
E(T) &= E(\bar{X} + S^2) = E(\bar{X}) + E(S^2) = 0 + 1 = 1, \\
E(T^2) &= E[(\bar{X} + S^2)^2] = D(\bar{X} + S^2) + [E(\bar{X} + S^2)]^2 \\
&= D(\bar{X}) + D(S^2) + 1 = \frac{1}{n} + \frac{2}{n-1} + 1 = \frac{n^2 + 2n - 1}{n(n-1)}.
\end{aligned}$$

### 题型一 应用分布或数字特征的性质求统计量的数字特征

**【例6.9】** 设总体 $X$ 的密度函数 $f(x) = \begin{cases} |x|, & |x| < 1, \\ 0, & \text{其他}, \end{cases}$ 又 $\bar{X}, S^2$ 分别为取自总体 $X$ 容量为 $n$ 的样本的均值和方差，则 $E\bar{X} = $ _______；$D\bar{X} = $ _______；$ES^2 = $ _______。

**【分析】** 由于 $E\bar{X} = EX$，$D\bar{X} = \frac{DX}{n}$，$ES^2 = DX$，由题设得
$$\begin{aligned}
EX &= \int_{-\infty}^{+\infty} xf(x)dx = \int_{-1}^{1} x|x|dx = 0, \\
DX &= EX^2 - (EX)^2 = \int_{-\infty}^{+\infty} x^2f(x)dx = \int_{-1}^{1} x^2|x|dx = 2\int_{0}^{1} x^3dx = \frac{1}{2},

所以 $E\bar{X} = 0, \quad D\bar{X} = \frac{1}{2n}, \quad ES^2 = \frac{1}{2}$。

**【例6.10】** 已知总体 $X$ 的数学期望 $EX = \mu$，方差 $DX = \sigma^2$，$X_1, X_2, \cdots, X_{2n}$ 是来自总体 $X$ 容量为 $2n$ 的简单随机样本，样本均值为 $\bar{X}$，统计量 $Y = \sum_{i=1}^{n} (X_i + X_{n+i} - 2\bar{X})^2$，求 $EY$。

**【解】** 由于总体分布未知，我们只好将 $Y$ 化简，应用数字特征性质计算 $EY$。由于
$$\begin{aligned}
Y &= \sum_{i=1}^n \left[ (X_i + X_{n+i})^2 - 4\bar{X}(X_i + X_{n+i}) + 4\bar{X}^2 \right] \\
&= \sum_{i=1}^{2n} X_i^2 + 2\sum_{i=1}^n X_i X_{n+i} + 4n\bar{X}^2 - 4\bar{X}\sum_{i=1}^{2n} X_i \\
&= \sum_{i=1}^{2n} X_i^2 + 2\sum_{i=1}^n X_i X_{n+i} - 4n\bar{X}^2 \quad \left( \sum_{i=1}^{2n} X_i = 2n\bar{X} \right),
\end{aligned}$$
又 $EX_i = \mu, \quad DX_i = \sigma^2, \quad EX_i^2 = \sigma^2 + \mu^2, \quad E\bar{X}^2 = D\bar{X} + (E\bar{X})^2 = \frac{\sigma^2}{2n} + \mu^2$，
所以
$$\begin{aligned}
EY &= \sum_{i=1}^{2n} EX_i^2 + 2\sum_{i=1}^n EX_i EX_{n+i} - 4n E\bar{X}^2 \\
&= \sum_{i=1}^{2n} (\sigma^2 + \mu^2) + 2\sum_{i=1}^n \mu^2 - 4n \left( \frac{\sigma^2}{2n} + \mu^2 \right) \\
&= 2n\sigma^2 + 2n\mu^2 + 2n\mu^2 - 2\sigma^2 - 4n\mu^2 = 2(n-1)\sigma^2.
\end{aligned}$$

**评注** 已知总体的分布（未必正态）确定样本均值的分布及有关问题只要注意下面 4 条即可：
1. 样本均值是简单样本中各个样本变量 $X_i$ 的算术平均值；
2. 各个 $X_i$ 与总体独立同分布，因此它们的各阶矩都相等（只要总体的相应矩存在）；
3. 关于独立同分布随机变量和的分布，参看第三章的六之（四）；
4. 关于总体分布的性质和特点，参看第二章之三。
