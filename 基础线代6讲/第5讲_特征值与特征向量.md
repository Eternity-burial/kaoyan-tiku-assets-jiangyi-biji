# 第5讲 特征值与特征向量

> 来源：基础线代6讲.pdf 物理页141–179（印刷1–39）｜本章完结于物理页179

## 0. 知识结构（框架）
- 特征值、特征向量：定义与求法 → 性质与重要结论 → 相似矩阵 → 相似对角化 → 实对称矩阵的相似对角化。

## 一、特征值、特征向量的定义与求法
- 定义：Aξ=λξ（ξ≠0）⇒ λ 是特征值、ξ 是特征向量。
- 求法：|λE−A|=0 求 λ；解 (λE−A)x=0 的非零解得特征向量。
- 求特征值的三个试根技巧（f(λ)=a_kλ^k+…+a1λ+a0=0）：
  1. a0=0 ⇒ 0 是根；
  2. 系数和 a_k+…+a1+a0=0 ⇒ 1 是根；
  3. 偶次项（含 a0）系数和=奇次项系数和 ⇒ −1 是根。
- 整系数多项式定理：f(x)=x^k+a_(k−1)x^(k−1)+…+a1x+a0（整数系数）的有理根都是整数，且都是 a0 的因子；再用带余除法降次 + 二次求根公式。
- 命题方法：|aA+bE|=0（或 aA+bE 不可逆）、a≠0 ⇒ −b/a 是 A 的特征值。

## 二、特征值、特征向量的性质与重要结论
### 1 特征值的性质
- λ0 是特征值 ⇔ |λ0E−A|=0；λ0 不是特征值 ⇔ |λ0E−A|≠0（可逆、满秩）。
- |A|=λ1λ2⋯λn；tr(A)=λ1+λ2+⋯+λn；k 阶主子式之和=任意 k 个特征值乘积之和。
- A^T 与 A 特征值相同，但 (λE−A^T)x=0 与 (λE−A)x=0 不同，特征向量要单独计算。
- f(A)=O 时，A 的任一特征值 λ 满足 f(λ)=0。
### 2 特征向量的性质
- ξ(≠0) 是 λ0 的特征向量 ⇔ ξ 是 (λ0E−A)x=0 的非零解。
- ① k 重特征值至多只有 k 个线性无关特征向量；
- ② 属于不同特征值的特征向量线性无关；
- ③ 同一特征值的特征向量的非零线性组合仍是对应特征向量（含某一系数为 0）；
- ④ 属于不同特征值的两个特征向量的非零线性组合不是任何特征值的特征向量（反证法；考 k1=k2=1）；
- ⑤ 一个特征向量不能属于两个不同特征值。
- 几何意义：Aξ=λξ 是线性变换沿特征方向伸缩 λ 倍；λ 只与自己的特征子空间配对。
### 3 常用矩阵的特征值与特征向量（表格）
| 矩阵 | 特征值 | 特征向量 |
|---|---|---|
| A | λ | ξ |
| kA | kλ | ξ |
| A^k | λ^k | ξ |
| f(A) | f(λ) | ξ |
| A⁻¹ | 1/λ | ξ |
| A* | \|A\|/λ（=其余特征值乘积） | ξ |
| A^T | λ | 需另算 |
| P⁻¹AP | λ | P⁻¹ξ |

- λ 在分母时设 λ≠0；实对称矩阵单根 λ：r(λE−A)=n−1，必有一个方程多余，可去任一方程仍同解。

## 三、矩阵的相似
- 定义：存在可逆 P 使 P⁻¹AP=B，记 A∼B。
- 性质：反身、对称、传递（最重要）。
- A∼B ⇒ ① |A|=|B|；② r(A)=r(B)；③ tr(A)=tr(B)；④ 特征值相同；⑤ r(λE−A)=r(λE−B)；⑥ 各阶主子式之和相等。
- 注：全部只是必要条件；至少一个不成立则不相似；相似不变量="各阶主子式之和"。
- 扩展：A∼B ⇒ A^k∼B^k、f(A)∼f(B)；A 可逆 ⇒ A⁻¹∼B⁻¹；A^T∼B^T；diag(A,B)∼diag(C,D)（若 A∼C、B∼D）。
- 判定方法：① 定义法（P 难求）；② 传递性：A∼Λ 且 B∼Λ ⇒ A∼B；③ 性质反求参数（必要条件）。
- 相似与特征值（蓝框）：特征值相同是相似的必要条件；特征值相同不一定相似；A、B 都是实对称矩阵时，特征值相同 ⇔ 相似。
- 求 C 使 C⁻¹AC=B：找 P、Q 使 P⁻¹AP=Q⁻¹BQ=Λ，则 C=PQ⁻¹。

## 四、矩阵的相似对角化
- 定义：存在可逆 P 使 P⁻¹AP=Λ（对角阵），Λ 为相似标准形；由 AP=PΛ。
- 可对角化条件：n 个线性无关特征向量；实对称必可；特征值全是单根必可；r 重根须有 r 个线性无关特征向量（少于 r 个则不可）。
- 求 P 步骤：求特征值 → 求各特征值的线性无关特征向量 → P=[ξ1,…,ξn]；ξ_i 与 λ_i 对应；P 不唯一。
- 反求 A：A=PΛP⁻¹。
- 求 A^k、f(A)：A^k=PΛ^kP⁻¹（对角元 λ_i^k）；f(A)=Pf(Λ)P⁻¹（对角元 f(λ_i)）。
- 判别是否可对角化步骤：① 实对称必可；② 特征值全单根则可；③ r 重根有 r 个线性无关特征向量则可，少于 r 个则不可。

## 五、实对称矩阵的相似对角化
- 充要条件：存在正交矩阵 Q，使 Q^T A Q=Λ=diag(λ1,…,λn)。
- 性质：
  1. 特征值为实数，特征向量可取实向量；
  2. 不同特征值的特征向量相互正交；
  3. 任意 n 阶实对称矩阵 A，存在正交 Q 使 Q^T A Q=Q⁻¹AQ=Λ；A=QΛQ^T（用转置替代求逆）。
- 步骤：求特征值 → 求特征向量 → 施密特正交化、单位化 → Q=[η1,…,ηn]；Q 不唯一。
- 施密特正交化：β1=α1；β2=α2−(β1,α2)/(β1,β1)β1；β3=α3−(β1,α3)/(β1,β1)β1−(β2,α3)/(β2,β2)β2。
- 几何意义：正交变换 x=Qy 旋转坐标系。
- 已知 Q 第 1 列 ⇒ 该列向量是 A 的特征向量，代入 Aξ=λξ 反求参数。

## 六、补充技巧
- |A*|=|A|^(k−1) 与 (AB)^T=B^T A^T 对不可逆矩阵也成立：tE+A 扰动可逆化证明，再令 t→0⁺ 连续延拓。
- 分块对角矩阵求幂：diag(B,C)^n=diag(B^n,C^n)；形如 2E+N（N 幂零）的矩阵可用二项展开求幂：C^n=2^nE+n·2^(n−1)N。
- 已知 A⁻¹ 的特征向量时，因 A 与 A⁻¹ 特征向量相同，不必求出 A⁻¹。
