# 第4讲 线性方程组

> 来源：基础线代6讲.pdf 物理页116–140（印刷页1–25）｜本章完结于物理页140

## 0. 知识结构（框架）
- 齐次线性方程组：有解的条件；解的性质；基础解系和解的结构；★★求解方法与步骤（必考知识点）。
- 非齐次线性方程组：有解的条件；解的性质；求解方法与步骤（注意强化计算能力）。
- 两个方程组的公共解；同解方程组。
- 核心观点：线性方程组与向量组其实是一回事。

## 一、基本概念与求解方法
- 系数矩阵 A：未知数前系数组成；增广矩阵 [A|b]：系数矩阵+常数项向量。
- 向量组形式：x1a1+x2a2+…+xnan=b；方程组与向量组本质上是一样的问题，解决方法一样。
- 求解方法：对增广矩阵作初等行变换化成行阶梯形矩阵，再求解。
- 蓝框：初等行变换属于同解变换，不改变未知数的值。

## 二、齐次线性方程组 Ax=0
- 有解条件：r(A)<n 时有非零解（x 不全为 0）；r(A)=n 时只有零解。
- 解的性质：解的组合仍是解（k1ξ1+k2ξ2 仍是 Ax=0 的解）。
- 解空间：r(A)=n 时解空间为 {0}；r(A)<n 时解空间维数 = n−r(A)，自由未知量个数 s=n−r。
- 基础解系：ξ1,…,ξ(n−r)；取法：自由变量依次取 1、其余取 0。
- 通解：k1ξ1+k2ξ2+…+k(n−r)ξ(n−r)，k_i 为任意常数。

## 三、非齐次线性方程组 Ax=b
- 有解条件：r(A)=r([A|b]) 时有解；=n 时唯一解；<n 时无穷多解；r(A)≠r([A|b]) 时无解。
- 通解结构：η + k1ξ1+…+k(n−r)ξ(n−r)，η 为特解、ξ 为 Ax=0 的基础解系。
- 解的性质：
  - ξ1、ξ2 是 Ax=b 的解 ⇒ ξ1−ξ2 是 Ax=0 的解。
  - ξ 是 Ax=0 的解 ⇒ kξ 是 Ax=0 的解。
- 求解步骤：增广矩阵初等行变换 → 行阶梯 → 定自由未知量 → 回代求特解与基础解系。

## 系数矩阵列向量与解的关系（蓝框）
- 齐次 a1x1+…+anxn=0 的解：使 a1,…,an 线性组合为零向量的组合系数。
- 非齐次 a1x1+…+anxn=β 的解：β 由 a1,…,an 线性表示时的表示系数。

## 四、两个方程组的公共解
- Ax=0 与 Bx=0 的公共解：满足 [A;B]x=0 的解，即联立方程求解；非齐次同理联立。
- 蓝框两种考查角度：
  ① 给出 Ax=0 的基础解系 ξ1,…,ξs 与 B 的表达式：通解 k1ξ1+…+ksξs 代入 Bx=0，求 k_i 关系，代回通解得公共解。
  ② 给出两组基础解系 ξ1,…,ξs 与 η1,…,ηt：令 γ=k1ξ1+…+ksξs=l1η1+…+ltηt，解系数关系求 γ。

## 五、同解方程组
- 定义：两个方程组解完全相同（Ax=0 与 Bx=0 同解）。
- 等价条件：
  - 互相代入验证：Ax=0 的解满足 Bx=0，且 Bx=0 的解满足 Ax=0；
  - r(A)=r(B) 且 Ax=0 的解满足 Bx=0（或反之）；
  - 三秩相同：r(A)=r(B)=r([A;B])。
- 蓝框注：理论分析着眼客观题；齐次方程组必有零公共解，求公共解主要求非零公共解，联立求解是基本办法。
- 操作（例题提炼）：对 (I) 增广矩阵行变换求通解，将通解代入 (II) 各方程求参数（令 C=0 可得参数值）。

## 六、秩的性质（蓝框）
- r(A)=r([A,B]) ⇒ r(A^T)=r([A^T;B^T])（B 每列可由 A 的列向量线性表示 ⇒ B^T 每行可由 A^T 的行向量线性表示）。
- 易错点：([A,B])^T=[A^T;B^T]，不是 [A^T,B^T]。
- ★★★★ Ax=0 与 A^T Ax=0 是同解方程组 ⇒ r(A)=r(A^T A)；四秩相同：r(A)=r(A^T)=r(A^T A)=r(AA^T)。
- 证明向量组线性无关：只需证由这些向量组成的行列式不为 0。
