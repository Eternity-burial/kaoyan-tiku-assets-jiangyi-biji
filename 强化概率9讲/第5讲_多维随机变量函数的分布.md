# 强化概率 第5讲 多维随机变量函数的分布

## 三向解题法框架（物理47-48）
- 求多维随机变量函数的分布 $O$（盯住目标）：
  - $O_1$ 多维$\to$一维：
    - 1.1 (离散型,离散型)$\to$离散型（$D_1$ 常规操作）
    - 1.2 (连续型,连续型)$\to$连续型（$D_1$ 常规操作 + $D_{25}$ 观察研究对象）
    - 1.3 (离散型,连续型)$\to$连续型（$D_1$ 常规操作）
  - $O_2$ 一维$\to$多维：离散型$\to$(离散,离散)（$D_1$）；连续型$\to$(离散,离散)（$D_1$）
  - $O_3$ 多维$\to$多维：(离散,离散)$\to$(离散,离散)；（连续,连续)$\to$(离散,离散)或(连续,连续)；（离散,连续)$\to$(离散,离散)（$D_1$ 常规操作）

## 一、多维$\to$一维 $O_1$（物理47-52）

### 1.1 (离散型,离散型)$\to$离散型
- $(X,Y)\sim p_{ij}$，$Z=g(X,Y)\Rightarrow Z$ 的分布律 $q_i$
- $X\sim p_k$，$Y\sim q_l$ 独立，常考 $Z=X+Y$、$Z=XY$、$Z=\max\{X,Y\}$、$Z=\min\{X,Y\}$
- 独立离散和的卷积：$P\{Z=k\}=P\{X+Y=k\}=p_0q_k+p_1q_{k-1}+\cdots+p_kq_0$
- $\max$：$P\{Z=k\}=P\{X=k,Y\le k\}+P\{X\le k-1,Y=k\}=p_k(q_0+\cdots+q_k)+(p_0+\cdots+p_{k-1})q_k$
- $\min$：$P\{Z=k\}=P\{X=k,Y\ge k\}+P\{X>k,Y=k\}=p_k(q_k+\cdots+q_l)+(p_{k+1}+\cdots+p_l)q_k$

### 1.2 (连续型,连续型)$\to$连续型
- **分布函数法**：$F_Z(z)=P\{g(X,Y)\le z\}=\iint_{g(x,y)\le z}f(x,y)dxdy$
- **换元法**（求 $(U,V)$ 联合密度）：设 $u=u(x,y),\ v=v(x,y)$ 一阶连续偏导且存在唯一反函数 $x=x(u,v),\ y=y(u,v)$，$J=\frac{\partial(x,y)}{\partial(u,v)}\ne0$，则 $f_{U,V}(u,v)=f[x(u,v),y(u,v)]\cdot|J|$；边缘 $f_U(u)=\int_{-\infty}^{+\infty}f_{U,V}(u,v)dv$
- **最值函数的分布**（物理52）：
  - $F_{\max}(z)=P\{\max\{X,Y\}\le z\}=F(z,z)$；独立时 $F_{\max}(z)=F_X(z)F_Y(z)$
  - $F_{\min}(z)=P\{\min\{X,Y\}\le z\}=F_X(z)+F_Y(z)-F(z,z)$；独立时 $=1-[1-F_X(z)][1-F_Y(z)]$
  - $n$ 个独立推广：$F_{\max}(z)=F_{X_1}(z)\cdots F_{X_n}(z)$；$F_{\min}(z)=1-\prod[1-F_{X_i}(z)]$
  - 特别地 $X_i$ iid（分布函数 $F$、密度 $f$）：$F_{\max}=[F(z)]^n$，$f_{\max}=n[F(z)]^{n-1}f(z)$；$F_{\min}=1-[1-F(z)]^n$，$f_{\min}=n[1-F(z)]^{n-1}f(z)$

### 1.3 (离散型,连续型)$\to$连续型
- $X\sim p_i$，$Y\sim f_Y(y)$，$Z=g(X,Y)$（常考 $X\pm Y$、$XY$ 等）
- $X,Y$ 独立：分布函数法 + 全概率公式求 $F_Z(z)$；不独立：分布函数法

## 二、一维$\to$多维 $O_2$（物理54）
- 离散型$\to$(离散,离散)：$X\sim p_i$，$\begin{cases}U=g(X)\\V=h(X)\end{cases}\Rightarrow(U,V)\sim q_{ij}$
- 连续型$\to$(离散,离散)：$X\sim f(x)$，$\begin{cases}U=g(X)\\V=h(X)\end{cases}\Rightarrow(U,V)\sim p_{ij}$
